## 修复「病虫害图片全部消失」（dev 模式）

- **根因不是数据**：18 张图在 `images/pest/`（7.1MB，全部被 git 跟踪），`pest_images` 表里 18 条 `file` 字段为 `/images/pest/*.jpg`，路径完全正确；Flask 侧 `/images` 200 + `image/jpeg`。
- 真正原因：`frontend/vite.config.ts` 的 dev proxy **只配了 `/api`**，`/images/*` 落到 Vite 的 SPA fallback，返回 `200 text/html`（index.html，1710 字节），`<img>` 解码失败 → 全部破图。
- 修复：在 `server.proxy` 里补上 `/images` 与 `/uploads`（都指向 `proxyTarget`）。Vite 会自动重载配置，无需重启。验证：18/18 全部 200 `image/jpeg`；`uploads/models_3d/*.png` 也恢复正常；`/api/health` 不受影响；无头 Chrome 实测「常见病虫害速查」卡片 0 破图、控制台零异常。
- **这是上游分支的缺陷**（dev-only；生产 nginx 自己伺服 `/images` 不会复现），值得向上游提 issue/PR。
- 覆盖度事实（非 bug）：`pest_entries` 45 条中只有 18 条配了实拍图，27 条本来就没有（图源逐个从 iNaturalist 挑选）；`aquatic` 作物 6 条全部无图。
