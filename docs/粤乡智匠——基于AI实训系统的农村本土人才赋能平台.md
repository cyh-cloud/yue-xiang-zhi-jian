**粤乡智匠——基于AI实训系统的农村本土人才赋能平台**

**项目说明书**

**项目名称**：粤乡智匠（Guangdong Rural Wisdom Artisan）

**项目方向**：乡村振兴 / 职业教育 / 人工智能 / 农村电商

**适用对象**：农村待业青年、返乡创业大学生、农村合作社成员

**核心理念**：低成本、场景化、本土化、AI伴学

**一、项目背景与痛点分析**

**1.1 项目背景**

随着国家乡村振兴战略的深入推进，农村地区对农业技术、电商运营和传统手工艺技能的需求急剧增长。然而，传统教育培训模式在农村地区面临诸多挑战，亟需通过数字化手段创新教育模式。

**1.2 核心痛点分析**

**痛点一：优质师资稀缺与边际成本高企**

**资源触达难：**城乡教育资源二元结构显著，专家级讲师下沉一线的时间与交通成本高昂，导致优质内容难以常态化覆盖。

**规模效应弱：**传统线下培训受限于物理空间，难以实现低成本的规模化复制，人均培训边际成本居高不下。

**供需匹配差：**通用型教材与本地特色产业需求错位，导致培训资源投入产出比低。

**痛点二：理论脱离实践**

- 传统教材内容枯燥，缺乏针对性
- 缺乏针对本地特色产业的实操指导
- 学习效果难以量化，技能转化率低

**痛点三：用户数字素养差异与交互壁垒**

**数字鸿沟显著：**农村留守群体多为中老年人，普遍存在"触屏恐惧"与数字技能匮乏问题，复杂APP操作劝退率高。

**语言交互障碍：**部分地区普通话普及率有限，专业术语理解困难，方言与标准教学内容之间存在天然隔阂。

**内驱力不足：**缺乏即时反馈与可视化的激励机制，农民难以在枯燥的理论学习中获得成就感，完课率普遍偏低。

**二、项目目标与价值定位**

**2.1 项目目标**

构建一套低成本、高互动的AI实训系统，将"田间地头"和"车间作坊"搬进数字平台，实现"AI老师"手把手教学，赋能农村本土人才发展。

**2.2 核心价值**

**教育普惠：**让优质教育资源触手可及

**技能提升：**针对性提升农业、电商、手工技能

**就业促进：**直接对接就业和创业机会

**文化传承：**数字化保存传统手工艺技法

**三、技术架构与开发方向**

**3.1 总体技术架构**

本系统遵循"端云协同、轻量化部署"的设计理念，采用"原生前端 + Flask后端 + 云端大模型API"的三层架构。前端使用原生HTML5/CSS3/JavaScript实现，无需构建工具，降低部署门槛；后端采用Python Flask框架，搭配SQLite嵌入式数据库，零依赖快速启动；AI能力通过SiliconFlow云端API调用Qwen3-32B大模型，无需本地GPU资源，兼顾智能性与低成本。

**3.2 技术选型**

| **维度** | **技术方案**                      | **说明**                                                     |
| -------- | --------------------------------- | ------------------------------------------------------------ |
| 前端开发 | HTML5 + CSS3 + JavaScript（原生） | 无框架依赖，响应式设计，适配PC与移动端，支持离线缓存         |
| 后端开发 | Python Flask + SQLite             | 轻量级RESTful API，嵌入式数据库，零配置快速启动              |
| AI引擎   | SiliconFlow API（Qwen3-32B）      | 云端大模型调用，支持农技问答、话术生成、文案创作、诊断分析等 |
| 数据存储 | SQLite（WAL模式）                 | 本地文件数据库，支持并发读写，适合轻量级部署                 |
| 部署方式 | 本地运行 / 云服务器               | python run.py一键启动，自动打开浏览器                        |

**四、核心功能模块设计**

**4.1 农业技能培训模块**

**广东特色农产品支持：**内置荔枝、龙眼、水产等广东特色农产品知识库，提供完整的生长周期日历。

**农时智能日历：**根据当前季节自动推送当月农事任务与管理要点（施肥、防虫、灌溉等）。

**AI农技问答：**接入Qwen3-32B大模型，支持自然语言提问，AI根据当前农时和作物状态给出专业建议。

**病虫害诊断：**内置常见病虫害数据库（霜疫霉病、炭疽病、蒂蛀虫等），提供症状识别与防治方案。

**4.2 电商运营实训模块**

**直播带货话术生成：**输入产品信息和直播风格，AI自动生成完整的直播带货脚本，包含开场白、产品介绍、互动话术、促单话术等。

**商品文案创作：**支持详情页、朋友圈、短视频、小红书等多种文案格式的AI自动生成。

**店铺装修指导：**AI根据店铺类型、平台和风格偏好，生成首页布局、色彩方案、详情页结构等装修方案。

**客服模拟训练：**模拟真实客服场景，支持多种客户性格类型，AI实时分析回复质量并提供改进建议。

**直播间模拟评分：**用户输入直播话术，AI从语速、情绪、互动、卖点突出等维度进行评分和反馈。

**4.3 手工技能传承模块**

**非遗技艺库：**收录广绣（国家级非遗）、潮汕木雕（国家级非遗）、石湾陶艺（国家级非遗）三大广东代表性非遗技艺。

**详细步骤拆解：**每项技艺提供6个完整步骤，包含详细描述和实用技巧，从入门到成品全流程指导。

**材料采购指南：**为每项技艺推荐具体材料、参考价格、购买渠道和注意事项，降低入门门槛。

**AR虚拟指导：**通过AI生成分步操作指引，模拟AR辅助学习体验。

**4.4 虚拟实训沙盒模块**

**病虫害AI诊断：**用户描述作物症状，AI通过引导式问答逐步缩小诊断范围，最终给出病因分析和防治方案。

**直播间模拟训练：**提供多种直播场景（新品发布、限时秒杀、农产品产地直供等），用户进行模拟直播并获得AI评分。

**手工技能AR指导：**选择手工项目后，AI生成详细的分步操作指引，包含工具准备、操作要点和常见错误提示。

**4.5 本土化资源库模块**

**方言交互支持：**支持粤语、客家话、潮汕话三大广东方言，提供方言与普通话的对照翻译和语音交互。

**成功案例库：**收录本地创业成功案例，记录案例背景、发展历程和经验启示，提供可复制的成功模式。

**政策信息推送：**整合最新农业政策解读、补贴申请指导和市场行情分析。

**4.6 就业与供应链对接模块**

**积分激励体系：**学习时长可兑换积分，积分可兑换化肥、种子优惠券等实物奖励。

**技能证书认证：**学员结业后自动生成"技能证书"，支持在线验证。

**人才供需匹配：**对接本地农业合作社和电商基地，精准匹配就业岗位。

**创业支持服务：**提供项目申报指导、资金申请协助和市场渠道对接。

**4.7 教师管理模块**

**学员管理：**支持学员的增删改查，按班级和学习方向分类管理。

**作业管理：**教师发布作业、学员提交作业、教师批改评分并给出反馈。

**考勤管理：**支持在线签到，记录出勤状态。

**公告管理：**发布教学通知和公告，支持置顶功能。

**学习数据分析：**统计学员学习进度、成绩分布、出勤率等数据。

**AI教学报告：**接入AI自动生成教学分析报告，包含学员表现评估和改进建议。

**消息中心：**支持师生之间的私信通信和系统通知。

**九、风险分析与应对策略**

**9.1 技术风险**

**风险一：AI识别准确率不足**

应对策略：采用多模型融合方案，建立本地知识库Fallback机制，AI服务不可用时自动降级到规则引擎。

**风险二：系统性能瓶颈**

应对策略：SQLite启用WAL模式优化并发，前端使用懒加载和骨架屏优化体验。

**风险三：方言识别困难**

应对策略：建立本地化方言词库，结合AI大模型的多方言理解能力。

**9.2 运营风险**

**风险一：用户接受度不高**

应对策略：开展线下培训，提供上门指导服务，优化界面降低使用门槛。

**风险二：内容更新维护困难**

应对策略：建立UGC机制，鼓励用户贡献内容，AI辅助内容生成。

**风险三：商业模式不清晰**

应对策略：探索政府购买服务、企业合作等多元化模式。
