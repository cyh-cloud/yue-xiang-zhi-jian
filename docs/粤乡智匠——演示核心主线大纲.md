## 六、时序自洽说明（防评审挑刺）

1. **课程链**：分支 1（教师上传→审核→上架）→ 主线②阿强看课。演示顺序上主线在前、供给线在后，属"内容早已存在"的正常叙事，口播补一句"这门课是李老师上周发布的"即可消除时序疑虑。
2. **政策链**：分支 2（政府发布）→ 主线④阿强看到。同上，口播带过。
3. **就业链（严格闭环）**：主线⑤内完成"投递→企业查看→标记意向→私信→阿强收到通知"，**在主线内时序闭环**，无倒挂；分支 3 只是展开这一段的完整过程。
4. **审核链**：课程与职位的上架都经普通管理员审核，分支 1/3 各展示一次，口径一致。

## 八、二次走查结果（12 项缺口纳入后复走主线）

**结论：主线 v2 逐节点复走，全部节点可走通，无硬伤级缺口。** 验证要点：
- 注册→标签→推荐位/订阅：标签可跳过，跳过时推荐退化为按方向排序、订阅需主动进入 06，均有空态兜底；

- 测验链：教师配置 → 观完作答 → AI 判分 → 计入档案与学情统计，口径（≥80% 完成）明确。
