# Triage labels

The skills speak in terms of five canonical triage goals. This file maps those roles to the actual label names in this repo's tracker.

| Role | Label in this repo | Meaning |
| --- | --- | --- |
| needs-triage | `needs-triage` | Needs maintainer evaluation |
| needs-info | `needs-info` | Waiting on reporter for more information |
| ready-for-agent | `ready-for-agent` | Fully specified, ready for an agent |
| ready-for-human | `ready-for-human` | Requires human implementation |
| wontfix | `wontfix` | Will not be accepted |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the matching label string from this table.

Edit the "Label in this repo" column when this repo's labels differ.
