# 粤乡智匠 需求输入

> 版本：v3（详细版，供 AI 编码实现）。流程描述到"主干 + 分支/异常/边界"粒度，可直接推导接口与状态机。

## 系统一句话

给广东省农村本土人才（农民/待业青年/学生等学员）提供**低门槛、本土化（方言交互、广东特色内容）、AI 伴学**的技能实训与就业对接平台；教师、企业、政府与后台管理端各配一个工作台。

## 范围约定（本需求的裁剪口径）

### 基准与裁剪

- 功能范围**以《功能需求.md》为唯一基准**，旧项目说明书与旧需求规格说明书仅用于补充术语和数据实体，冲突处以新文档为准；经**演示主线三轮走查**补充的功能（细化口径 v2/v3）为本期需求的有机组成部分。
- 本期**不纳入**：作业发布与批改、考勤签到、技能证书（结业获得/在线验证）、首页轮播图、农产品求购信息、**3D 模型功能（超出技术栈能力边界）**、**论坛社区（明确不做）**。相关子系统在"边界"中注明。
- **暂缓项**：无。原 P2 悬浮客服已**转正为 12-AI 学伴**（全角色可用，后台管理端不展示，见 v3 口径）。
- "就业与供应链对接"因砍掉求购信息，模块定名**就业对接**。
- 政策类别扩展包含**创业支持**，不单独立栏目。
- 外部依赖：**AI 大模型服务**（云端 API，概念级外部依赖，非本平台子系统），承载问答、生成、诊断、评分、出题、报告、学伴等 AI 能力。

### 细化口径 v1（权限与机制）

- **管理员权限细分**：后台设**超级管理员**与**普通管理员**两类角色。超级管理员拥有全平台所有数据的管理权限；普通管理员定位为**内容运维管理**（内容审核、违规评论删除与举报处理、预置内容维护、奖品库与兑换履约管理），**用户等敏感数据对其不可见、无入口**（账号管理、用户列表、用户详情、完整兑换记录仅超管可见；履约单按 v2 口径开放业务字段视图）。
- **数据看板按角色区分**：各后台角色（超级管理员/普通管理员/政府/企业/教师）均配数据看板，**只展示与自身职责相关的数据**——政府不可见用户信息与培训数据（用户数、用户画像类统计与课程/学习类统计均不向政府展示）。
- **注册角色限制**：自助注册仅开放**学员、教师**两类角色；企业/政府/超级管理员/普通管理员账户由超级管理员创建（分配初始凭证），超管初始账户由系统预置。
- **积分体系为平台级**：积分获取覆盖全平台有效学习行为，兑换入口与积分商城设于 05-手工传承；**积分规则（折算比率、每日获取上限、积分有效期）可由超级管理员配置修改**。
- **AI 不可用统一策略**：仅**农业问答**降级到本地病虫害知识库；其余 AI 功能（诊断、电商实训、AR 指引、方言助手、简历优化、学情报告、课后测验、AI 学伴等）直接提示"AI 服务暂时不可用"，对应手动功能不受影响。
- **公告分发口径**：系统公告（管理员发布→全员）与教学公告（教师发布→全体学员）以**系统通知形式经 02 群发**，学员在消息中心查看，不单建公告栏页面。
- **答疑互动区口径**：答疑互动区 = **课程视频与非遗视频的评论区**（学员提问留言、教师回复），不单建讨论区模块；评论纳入后台监管范围。
- **内容审核与监管口径**：**先审后发**对象三类：课程视频（08 教师发布）、职位（09 企业发布）、非遗教学视频（05 展示），审核通过/驳回均经 02 站内通知提交者，驳回附审核意见；**评论为即时发布 + 事后监管**（不进预审队列）：管理员可删除违规评论、处理学员举报，与答疑互动口径一致。
- **学员数据口径**：本平台**不做学员档案管理**（教师后台无学员增删改查）；学员学习方向由学员自选（默认"综合"），作为统计与 AI 学情报告的方向维度。

### 细化口径 v2（演示主线走查补充，已纳入）

- **兴趣标签体系**：学员注册引导时选择**兴趣标签**（关注的作物类目、技能兴趣、岗位类别，多选、可跳过、个人资料可改）；课程/职位/政策按标签组织，支撑推荐与订阅推送。
- **技能档案（学习成果集）**：系统自动汇总学习成果（话术脚本、模拟训练评分、课后测验成绩、学习记录）生成技能档案；**学员控制可见范围**（默认仅自己可见），投递简历时可选择附带，企业查看申请时可见——打通"培训→就业"的证据链。
- **AI 课后测验（智能出题）**：教师发布课程时须填写**课程简介/知识点要点**（文本，同时作为课程展示摘要与 AI 出题输入——AI 为文本大模型，无法直接读取视频文件内容），可开启"AI 课后测验"，AI 依据课程简介自动生成 3~5 道选择题/判断题（教师可预览修改后保存）；学员观看完成后作答，AI 判分+讲解，成绩计入学习统计与技能档案。诊断结束后亦可发起可选自测（依据诊断文本内容出题）。
- **症状快捷选择器**：病虫害诊断首步改为点选式——选作物部位 → 选症状表现 → AI 接手引导追问，替代纯文字描述门槛。
- **兑换履约状态**：兑换成功生成履约单，状态流转**待发放 → 已发放 → 已核销**；**待发放可取消**（学员申请或管理员操作：积分回退、库存回滚、02 通知）；已发放/已核销不可取消。履约视图对普通管理员开放（显示学员编号/昵称+奖品+状态，不含联系方式等敏感明细）；完整兑换记录仅超管可见。
- **个性化推荐**：基于兴趣标签与学习行为的轻量推荐——课程区块"为你推荐"、岗位列表"推荐岗位"（规则匹配版）。
- **订阅与提醒推送**：学员订阅农产品（获当月农事提醒）与政策类别（新政策上架推送），复用 02 消息通道。
- **AI 问答语音输入**：农技问答/诊断支持语音提问（复用方言语音识别能力，识别转文字后进入问答）。
- **课程完成判定**：观看进度 ≥80% 记为完成，作为进度/完课率统计口径。
- **密码找回（管理员重置模式）**：不做自助找回；忘记密码 → 联系管理员，超管在账号管理执行"重置密码"（重置为初始密码），用户以初始密码登录后自行修改。
- **举报与意见反馈**：学员可举报违规评论（进入举报队列由管理员处理）；提供意见反馈入口。

### 细化口径 v3（三次走查补充，本轮纳入）

- **AI 学伴（原悬浮客服转正）**：全站悬浮 AI 助手，**全角色可用**（学员/教师/企业/政府门户均可唤起）；**后台管理端（超级管理员/普通管理员门户）不展示 AI 学伴入口**。能力：平台使用答疑 + 学习问题引导 + 方言语音提问；不做业务代办（详见 12）。
- **诊断复诊记录**：诊断结果页提供"记录防治效果"入口，学员填写防治后状态（好转/无变化/恶化）+ 备注 → 生成复诊记录挂入诊断会话历史；可基于复诊记录再次发起诊断，形成"诊断→防治→复诊"闭环。
- **企业申请列表筛选排序**：求职申请列表支持按职位、状态（待处理/已查看/意向沟通/不合适）、投递时间筛选与排序。
- **积分有效期**：并入超管积分规则配置——**默认永久有效**；可配置有效期（按自然年过期）；到期积分自动清零并经 02 站内通知学员（通知含清零积分数）。
- **待审核内容可编辑**：课程/职位处于"待审核"状态时提交者可直接编辑（保持待审核状态，编辑后内容进入最新审核）；已上架内容编辑 → 重新进入待审核。
- **企业申请状态可改标**：企业可随时更改申请状态标记，以最新状态为准，每次变更均经 02 通知学员。

## 子系统详述

### 01-账户与门户

- 职责：注册登录与会话管理，注册引导选择兴趣标签，按角色路由门户，首次使用分步蒙层新手引导，承载学员个人资料与课程聚合入口。
- 角色：全部六种角色（学员/教师/企业/政府/超级管理员/普通管理员）；主角是学员。
- 核心流程：
  1. 注册（仅学员/教师）：
     - 新用户 → 注册页 → 选择角色（下拉/单选，仅"学员/教师"两项）→ 填写用户名/密码/确认密码/姓名 → 提交 → 逐项校验：
       - 用户名为空/格式不符 → 表单错误提示，聚焦对应字段；
       - 用户名已存在 → 提示"用户名已被占用"，要求重填；
       - 密码为空/长度不足 → 表单错误提示；
       - 两次密码不一致 → 提示重新输入；
       - 姓名为空 → 表单错误提示；
     - 校验全部通过 → 创建账户 → 若角色=学员 → 初始化个人资料（学习方向默认"综合"）→ 进入**兴趣标签引导页**（作物类目/技能兴趣/岗位类别三组多选，可全跳过）→ 保存（或跳过）→ 自动登录进入学员端门户；若角色=教师 → 自动登录进入教师工作台。
  2. 登录：
     - 用户 → 输入用户名/密码 → 分支校验：
       - 用户名不存在或密码错误 → 统一提示"用户名或密码错误"（不区分暴露哪个错），可重试；
       - 账户被禁用（由 11 禁用）→ 拒绝登录，提示"账户已被禁用，请联系管理员"；
       - 校验通过 → 按角色路由到对应门户（学员端/教师/企业/政府/管理后台）→ 创建会话（有效期 24h，可配置）；
     - 会话过期后任何操作 → 自动跳转登录页，重新登录后可继续原操作；
     - 忘记密码 → 登录页提示"请联系管理员重置密码"（超管重置流程见 11）。
  3. 新手引导：任一角色首次登录 → 分步蒙层引导（逐个高亮该角色门户核心功能入口+文字说明）→ 分支：走完全部步骤 → 记录"已引导"；点击"跳过" → 记录"已引导"；中途关闭/离开 → 不记录 → 下次登录再次出现。已引导账户此后不再出现引导。
  4. 个人资料（学员）：
     - 查看/编辑：姓名、联系方式、学习方向（农业/电商/手工/综合，默认"综合"）、兴趣标签（可增删）；
     - 学习方向或标签变更 → 即时影响：课程推荐池、岗位推荐区、08 统计的方向分组与 AI 学情报告口径；
     - 结构化简历编辑与 AI 优化流程见 07-就业对接。
  5. 课程聚合入口（学员端）：
     - 门户"课程"聚合页 → 按学习方向（农业/电商/手工）Tab 筛选全部**已上架**课程（数据来自 08）→ 与 03/04/05 模块内课程区块同源同数据；
     - 列表排序：默认按兴趣标签匹配的**推荐位**置顶，其余按上架时间倒序；
     - 无课程 → "暂无课程"空态。
- 边界：不开放企业/政府/管理员自助注册（账户由 11 创建）；不含各角色门户内业务功能（见 03~12）；不含角色资质审批；不含自助密码找回（管理员重置模式）；不含论坛。
- 数据触点：读写 用户账户、登录会话、（学员）个人资料（学习方向）、兴趣标签、简历。
- 验收标准：
  1. 注册表单各校验分支（用户名重复/必填缺失/密码不一致）均有明确提示；学员注册后进入兴趣标签引导且可跳过；
  2. 凭证错误（不区分提示）、账户禁用、忘记密码三条路径处理正确；会话过期自动跳转登录页；
  3. 首次登录蒙层引导：走完/跳过记录不再出现，中途离开下次再出现；
  4. 学习方向与标签修改后推荐内容与方向统计同步变化；课程聚合页按方向+推荐排序展示，空态正常。
- 依赖：无（其余子系统均依赖本子系统）。

### 02-消息与通知

- 职责：统一承载站内私信（限定会话范围）、系统通知（事件枚举触发）、订阅推送的收发、已读状态与未读角标管理。
- 角色：全部角色。
- 核心流程：
  1. 私信（双向，会话范围矩阵）：
     - 允许的组合：教师↔任意学员；企业↔**向本企业投递过简历的学员**；学员→任意教师；学员→其投递岗位的对应企业；
     - 禁止的组合：学员↔学员、企业↔未投递学员、企业↔企业、教师↔教师等范围外组合 → 发起入口不可见/接口拒绝；
     - 发送 → 接收方消息中心未读角标 +1 → 接收方可回复 → 多轮往来全部留痕（按会话线程组织，时间正序展示）。
  2. 系统通知（事件枚举，触发即发）：
     - 审核结果（先审后发三类）：课程视频/职位/非遗教学视频 审核通过 → 通知提交者（教师/企业）"已通过并上架"；驳回 → 通知附审核意见；
     - 求职事件：学员投递成功 → 通知对应企业（含学员姓名与岗位标题）；企业标记/改标申请状态（已查看/意向沟通/不合适）→ 通知学员；企业删除职位导致未处理申请关闭 → 通知相关学员（"岗位已关闭"）；
     - 公告群发：系统公告（管理员发布）→ 全部用户；教学公告（教师发布）→ 全体学员；
     - 兑换与履约：兑换成功 → 通知学员（含积分消耗与奖品信息）；履约发放（待发放→已发放）→ 通知学员；履约取消 → 通知学员（含积分回退信息）；积分过期清零 → 通知学员（含清零数额）；
     - 订阅推送：农事月度提醒（每月初按订阅农产品推送当月农事要点）；新政策上架（按订阅类别推送，含政策标题与类别）。
  3. 已读管理：
     - 未读角标 = 未读私信数 + 未读通知数（角标全局展示于顶栏/门户）；
     - 一键全部已读 → 全部消息标记已读 → 角标清零；
     - 清除已读 → 已读消息从列表移除（不展示），未读消息保留；
     - 单条消息点开 → 该条标记已读。
- 边界：不含短信/邮件等站外推送；不含智能客服会话（由 12-AI 学伴承载）；不做消息撤回。
- 数据触点：读写 私信、系统通知；读 用户账户、订阅关系。
- 验收标准：
  1. 会话范围矩阵全部组合验证：允许组合可收发、范围外组合无法发起；未读角标随收发准确变化；
  2. 事件枚举逐项触发验证：审核通过/驳回、投递、状态变更、申请关闭、公告、兑换/履约三事件、积分过期、农事提醒、新政策推送均送达正确接收者，驳回通知附意见；
  3. 一键全部已读清零、清除已读移除、单条点开已读均生效。
- 依赖：01-账户与门户。

### 03-农业技能

- 职责：农时智能日历、语音/文字 AI 农技问答（可降级本地知识库）、点选式病虫害多轮诊断、复诊记录、课程区块（含测验与推荐）。
- 角色：学员是主角。
- 核心流程：
  1. 农时智能日历：
     - 进入模块 → 默认展示**上次选择的农产品**（无历史则列表首项）的当月日历 → 展示该产品当月农事任务与管理要点，含节气标注和当月农事提示；
     - 切换农产品（荔枝/龙眼/水产等，来自 11 预置目录）→ 日历内容随产品与月份联动刷新；
     - 前/后翻月 → 查看对应月份农事安排；超出预置数据范围的月份 → 显示"暂无数据"空态；
     - 订阅：学员可订阅关注的农产品 → 每月初经 02 收到该产品当月农事提醒；可随时取消订阅。
  2. AI 农技问答：
     - 输入（两种方式）：文字输入；或按住语音按钮语音提问（调用语音识别 → 转文字 → 展示识别结果）→ 分支：语音识别失败（噪音/不可识别）→ 提示"未能识别，请重试或改用文字输入"；
     - 提交 → AI 流式输出回答（逐字展示）→ 回答完毕自动生成 **3 个追问建议**（可点击）；
     - 点击追问建议 = 以该问题发起新一轮问答 → 同样流式输出+新追问建议 → 可多轮深入；
     - 问答历史记录按时间倒序可回看；
     - **AI 服务不可用分支**：自动降级本地病虫害知识库检索 → 有匹配条目 → 返回最匹配内容并标注"离线知识库回答"（不生成追问建议）；无匹配 → 提示"暂无法回答，建议稍后再试"。
  3. 病虫害 AI 诊断：
     - 首步（点选式）：选农产品 → 选发病部位（叶/果/枝干/根/整株等）→ 选症状表现（多选：斑点/脱落/虫蛀/萎蔫/畸形等）→ 进入 AI 诊断；
     - AI 引导式追问：AI 依据点选信息追问补充细节（如"病斑颜色/出现时间/蔓延范围"），学员文字（或语音转文字）回答 → **最多 5 轮** → AI 判定信息充分 → 输出**病因分析 + 防治方案**；
     - 中途退出 → 会话保留（状态"进行中"）→ 可返回继续或放弃重开；
     - 诊断会话历史可回看（含点选信息、追问回答、结论）；
     - **AI 自测（可选）**：诊断结果页提供"AI 自测"入口 → AI 依据本次诊断文本生成 3~5 道小题 → 学员作答 → AI 判分 + 逐题讲解 → 成绩计入技能档案；
     - **复诊记录**：诊断结果页提供"记录防治效果"入口 → 学员填写防治后状态（好转/无变化/恶化）+ 备注 → 生成复诊记录挂入该诊断会话；复诊记录随会话历史可查；可在复诊记录基础上再次发起诊断（预填上轮信息）；
     - **AI 服务不可用分支**：提示"AI 服务暂时不可用"（诊断与自测均无降级），点选信息可暂存，恢复后继续。
  4. 课程区块（农业方向）：
     - 区块内浏览农业方向已上架课程（数据来自 08）→ 顶部"为你推荐"位（基于兴趣标签与学习行为的推荐）；
     - 观看课程 → 播放器记录观看进度（≥80% 记为完成，断点续播）；
     - 观看完成后 → 若该课程教师开启了 AI 课后测验 → 测验入口点亮 → 作答（AI 判分+讲解，成绩入技能档案与学习统计）；
     - 视频评论区提问留言（教师回复见 08）；
     - 无课程/无推荐 → 各自空态。
- 边界：不含病虫害图片/拍照识别（点选+文字描述）；不含农产品价格行情与交易；不含施肥/灌溉物联网接入；降级仅覆盖问答。
- 数据触点：读 农产品目录、农时日历、病虫害知识库（均为 11 预置）、课程（农业方向+标签）、兴趣标签；读写 问答记录、诊断会话（含复诊记录）、测验记录、学习行为（观看进度/时长）、农产品订阅关系。
- 验收标准：
  1. 日历默认产品与月份正确、切换/翻月联动刷新、超范围空态；订阅后月初收到提醒、取消后不再收到；
  2. 问答文字/语音输入均可用，语音识别失败有提示；流式输出+3 追问建议；AI 不可用降级本地库（带标识、无追问建议）、本地库无匹配有提示；
  3. 诊断点选首步（产品→部位→症状）+ 追问（≤5 轮）+ 病因与防治方案；中断会话可恢复；AI 自测可作答判分；复诊记录可提交、可回看、可基于复诊再诊断；
  4. 课程观看进度跟踪（≥80% 完成、断点续播）；完成后测验入口点亮；推荐位按标签出内容；空态正常。
- 依赖：01、02（订阅推送）、外部 AI 大模型服务、08（课程）、11（预置内容）。

### 04-电商运营实训

- 职责：直播话术生成、直播间模拟训练与四维评分、文案提示词训练（AI 现场生成案例）、店铺装修指导、客服模拟训练。
- 角色：学员是主角。
- 核心流程：
  1. 直播话术生成：
     - 输入产品信息（名称/卖点/价格等）+ 选择直播风格（热情/专业/幽默）→ AI 生成完整脚本，**结构必须完整**：开场白、产品介绍、互动话术、促单话术；
     - 可"重新生成"或换风格再生成（同输入可多次生成，保留最新）；
     - 生成记录保存可回看（含输入参数与输出脚本），并计入技能档案；
     - AI 不可用 → 提示"AI 服务暂时不可用"（无降级）。
  2. 直播间模拟训练（文字输入）：
     - 选择预设场景：开场白/产品介绍/互动引导/促单话术/异议处理；
     - 按场景逐环节输入**文字话术**（模拟直播口播）→ 可修改后提交；
     - 完成训练 → AI 从四维度量化评分并给改进建议：语速节奏（句式节奏）、情绪感染力（语气用词）、互动引导、卖点突出；
     - 训练与评分记录保存可回看，评分计入技能档案；
     - 说明：本期文字输入，四维评分基于文本分析；语音输入与录音评分不在本期；
     - AI 不可用 → 提示，训练无法进行。
  3. 文案提示词训练（智能出题式）：
     - 选择商品类型/场景 → AI 现场生成一份**劣质/失败文案案例**；
     - 学员阅读 → 提交评判（指出问题+理由，文字）→ 系统展示 **AI 参考评判**供对照；
     - 学员撰写优化后的提示词 → 提交 → AI 按新提示词重新生成文案 → 系统对比新旧两版差异并点评提示词优化效果；
     - 训练记录（案例/评判/提示词/两版文案/点评）保存可回看；
     - AI 不可用 → 提示（强依赖，无降级）。
  4. 店铺装修指导：
     - 输入店铺类型 + 平台（淘宝/拼多多/抖音小店等）+ 风格偏好 → AI 输出装修方案（首页布局、色彩方案、详情页结构、导航分类）；
     - 方案记录保存可回看；AI 不可用 → 提示。
  5. 客服模拟训练：
     - 进入训练 → AI 扮演客户发起咨询（预设咨询场景）→ 学员逐轮回复 → **每轮回复后 AI 即时分析回复质量**并给改进建议 → 学员选择结束 → 输出整场总结；
     - 对话记录保存可回看；AI 不可用 → 提示。
  6. 课程区块（电商方向）：同 03 机制（方向=电商的课程 + AI 课后测验 + 为你推荐），空态同。
- 边界：文案创作**不提供一键生成成品文案**功能（只做案例评判+提示词优化训练）；评分仅属模拟训练输出环节，不支持语音输入与独立录音评分（文本分析）；不含真实电商平台/店铺 API 对接；AI 不可用时各功能无降级。
- 数据触点：读 课程（电商方向+标签）、兴趣标签；写 话术生成记录、模拟训练与评分记录、文案训练记录、店铺装修方案记录、客服模拟对话记录、测验记录。
- 验收标准：
  1. 任一风格生成的话术均含四段完整结构；重新生成/换风格生效；记录可回看；
  2. 模拟训练各场景可走通并输出四维评分与改进建议；
  3. 文案训练五步全流程（案例→评判→对照→优化提示词→对比点评）可走通且留痕；
  4. 店铺装修方案结构完整；客服模拟逐轮即时分析+整场总结；
  5. AI 不可用时以上功能统一提示，不出现报错页面。
- 依赖：01、外部 AI 大模型服务、08（课程）。

### 05-手工传承

- 职责：四大非遗技艺学习、材料采购指南、教学视频交互、AR 分步指引、平台积分体系与兑换商城（含履约管理）。
- 角色：学员是主角；教师上传教学视频；超级管理员/普通管理员负责审核、奖品库、履约与预置内容。
- 核心流程：
  1. 技艺学习：
     - 选择非遗技艺（广绣/潮汕木雕/石湾陶艺/阳江漆器）→ 项目介绍页（起源/历史/特色）；
     - 进入 6 步骤操作指南（每步含描述+实用技巧）→ 逐步学习 → 学习时长计入积分（受每日上限约束）；
     - 学习进度（已完成步骤数/6）记录，断点续学。
  2. 材料采购指南：
     - 每项技艺提供材料采购指南：材料名称/参考价格/购买渠道/注意事项 + **淘宝搜索关键词**；
     - 学员按关键词自行站外采购（平台不介入交易，不担保价格与质量）。
  3. 教学视频资源：
     - 教师 → 上传视频文件 + 填写标题 → 挂到指定技艺 → 提交审核 → 分支：
       - 审核通过 → 学员在该技艺详情页观看，可在视频内评论、留言（教师可回复，见 08 答疑互动）；
       - 审核驳回 → 02 通知教师（附审核意见）→ 教师修改后重新提交；驳回资源学员端不可见；
       - 待审核 → 学员端不可见；待审核期间教师可直接编辑（保持待审核）。
  4. AR 分步操作指引：
     - 选择手工项目 → AI 生成分步操作指引（含工具准备、操作要点、常见错误提示）→ 步骤化展示；
     - 使用时长计入积分；AI 不可用 → 提示（无降级）。
  5. 积分体系（平台级）：
     - 获取：有效学习行为按累计时长折算积分——观看课程视频（任意方向）、学习技艺操作步骤、使用 AR 分步指引；
     - 规则：折算比率与每日获取上限由超管配置（见 11）；**积分有效期**：默认永久，可由超管配置按自然年过期，到期自动清零并 02 通知学员；
     - 积分流水（获取/消耗/过期）可查询，按时间倒序。
  6. 兑换与履约：
     - 兑换：学员 → 积分商城浏览**上架**奖品（名称/所需积分/库存）→ 点击兑换 → 三重校验：
       - 积分不足 → 提示"积分不足，还差 N 分"，不可兑换；
       - 奖品已下架 → 置灰不可点；
       - 库存为 0 → 置灰并标注"已抢完"；
     - 校验通过 → 原子扣减学员积分与奖品库存 → 生成履约单（状态：**待发放**）→ 02 通知学员（含积分消耗与奖品信息）；
     - 履约流转：管理员执行发放（待发放→**已发放**，02 通知学员）→ 学员确认收货（→**已核销**）；学员也可在待发放状态**取消兑换**（→**已取消**：积分回退、库存回滚、02 通知）；已发放/已核销不可取消；
     - 学员端"我的兑换"列表 → 履约单状态全程可查。
- 边界：**不含 3D 模型功能**（超技术栈边界，本期不做）；不含真实 AR 设备/摄像头空间追踪（AI 生成分步指引，模拟 AR 体验）；不含非遗作品展示交易；材料采购仅提供指南；不含考勤/作业；积分规则学员侧不可配置。
- 数据触点：读 非遗技艺/步骤指南/材料采购指南（预置）、奖品库、课程（手工方向+标签）、兴趣标签、积分规则（比率/上限/有效期）；读写 教学视频、资源评论、积分账户/流水、兑换记录与履约单、学习行为（步骤进度/时长）。
- 验收标准：
  1. 四大技艺齐全（介绍+6 步骤+材料指南含淘宝关键词），步骤进度断点续学；
  2. 教学视频审核通过可观看评论、驳回不可见且教师收通知、待审核可编辑；
  3. 积分按时长累计受每日上限约束、按超管配置折算、有效期规则生效（到期清零+通知）；流水可查；
  4. 兑换三校验（不足/下架/库存0）正确拦截；兑换原子扣减；履约四态流转（待发放→已发放→已核销 / 待发放→已取消）正确，取消时积分回退+库存回滚+通知；学员端履约状态可查。
- 依赖：01、02、08（视频上传）、11（审核+奖品库+履约+预置内容+积分规则）、外部 AI 服务。

### 06-本土资源

- 职责：三大方言语音交互（限本模块 AI 方言助手）、本地成功创业案例展示、政策（含创业支持）/新闻浏览与订阅。

       - 识别成功 → 文字展示识别结果 → AI 理解并生成回答 → 以该方言语音播放 + 文字展示（附普通话对照）；
       - 识别失败（噪音/不可识别）→ 提示"未能识别，请重说或改用文字"；
       - AI 服务不可用 → 提示"AI 服务暂时不可用"；
     - 方言范围：仅本模块支持方言问答与翻译；该语音识别能力复用为 03 问答语音输入的底层；其余模块 AI 功能以普通话/文字为主。
  2. 成功案例：
     - 浏览本地成功创业案例列表（预置内容）→ 进入详情页查看背景、历程、经验启示；本期无用户投稿。
  3. 政策浏览与订阅：
     - 按七类筛选：补贴/电商/非遗/培训/认证/综合/**创业支持**；

     - 政策详情页浏览计入累计点击浏览量（供 10/11 看板统计）。
  4. 新闻浏览：
     - 按三类浏览：新闻/灾害预警/政策更新；
     - 新闻发布即可见、删除即不可见（无单独上下架）；浏览计入累计点击浏览量。
- 边界：不含方言语音包离线使用；不含用户自行发布资讯（内容只来自政府与平台预置）；不含补贴线上申领办理；不含论坛。
- 数据触点：读 政策（含状态与类别）、新闻资讯、成功案例（预置）；写 方言交互会话记录、政策/新闻浏览计数、政策类别订阅关系。
- 验收标准：
  1. 三大方言各完成一次"语音提问→方言语音回答+普通话对照"；识别失败与 AI 不可用分支均有提示；语音入口醒目；
  2. 政策七类筛选正确；仅上架可见；下架/删除后不可见；订阅类别后新政策上架收到推送、取消后不再收到；
  3. 案例列表与详情正常；政策/新闻浏览计数累计正确。
- 依赖：01、02（订阅推送）、10（政策/新闻数据源）、11（预置内容）、外部 AI 服务（方言理解与语音）。

### 07-就业对接

- 职责：岗位浏览与推荐、结构化简历维护（可选 AI 优化）、技能档案、简历投递与状态跟踪、岗位收藏。
- 角色：学员是主角；企业供岗。
- 核心流程：
  1. 简历维护：
     - 创建/编辑结构化简历：教育经历、工作经历、技能特长（结构化字段）→ 保存；
     - AI 优化（可选）：点击"AI 优化" → AI 给出优化建议或改写稿 → 学员**确认采纳**（替换生效）或**放弃**（保留原版）→ 保存；
     - AI 不可用 → 优化入口提示"AI 服务暂时不可用"，手动编辑不受影响。
  2. 技能档案（学习成果集）：
     - 系统自动汇总学习成果：直播话术脚本、模拟训练评分、课后测验成绩、学习记录（课程完成情况）；
     - 学员在"我的技能档案"**勾选可见范围**（哪些成果项对外展示；默认全部仅自己可见）；
     - 投递时可选择"附带技能档案"；企业查看申请时可见附带的档案内容。
  3. 岗位浏览与投递：
     - 岗位列表：标题、公司、薪资、地点、描述；顶部**"推荐岗位"区**（基于兴趣标签与学习行为匹配职位类别）；
     - 查看岗位详情 → 点击"投递简历" → 前置校验分支：
       - 无简历 → 拦截并引导先创建简历（跳转简历编辑）；
       - 已投递过该岗位 → 提示"已投递该岗位"，禁止重复投递；
       - 岗位未上架/已删除 → 学员端列表与详情均不可见，无从投递（兜底）；
     - 校验通过 → 生成求职申请（附简历快照；**可选附带技能档案**）→ 02 通知对应企业 → 进入"我的投递"列表；
     - "我的投递"状态跟踪：随企业标记更新——待处理/已查看/意向沟通/不合适/岗位已关闭（企业删除职位触发）。
  4. 岗位收藏：
     - 收藏/取消收藏岗位 → 收藏列表集中查看；
     - 已收藏岗位被企业删除 → 收藏项标记"岗位已关闭"，不可投递，可手动移除。
  5. 岗位上架链路（依赖链）：企业发布职位 → 11 审核 → 上架 → 学员可投递（详见 09/11）。
- 边界：不含农产品求购信息（本期剔除）；不含线上面试、电子签约、入职流程管理；不含企业主动搜索人才库（企业只处理主动投递）；不含投递撤回（投出后不可撤，岗位关闭由企业触发）；AI 简历优化仅产出建议/改写稿，须学员确认采纳，不自动覆盖已保存简历。
- 数据触点：读写 简历（含 AI 优化采纳结果）、技能档案（含可见范围勾选）、岗位收藏；读 岗位（含审核状态）、兴趣标签；写 求职申请（含状态、附带档案标记）。
- 验收标准：
  1. 简历结构化编辑保存正常；AI 优化建议采纳/放弃两分支均正确；AI 不可用仅影响优化入口；
  2. 技能档案自动汇总四类成果；可见范围勾选生效（未勾选项企业不可见）；投递附带档案在企业端申请详情可见；
  3. 投递前置校验三分支（无简历/重复投递/不可见岗位）正确；投递成功通知企业；
  4. "我的投递"五种状态与企业操作同步；收藏/取消收藏、岗位已关闭标记与移除正常；
  5. 推荐岗位区与兴趣标签匹配（改标签后推荐变化）。
- 依赖：01、02（通知）、09（岗位数据源）、11（职位审核）、外部 AI 服务（简历优化）；技能档案数据来自 03/04/05。

### 08-教师工作台

- 职责：课程视频发布与管理（审核+课程简介+内容标签+AI 测验配置）、教学公告、答疑互动、数据看板与 AI 学情报告。**不含学员档案管理**。
- 角色：教师是主角。
- 核心流程：
  1. 课程视频发布与管理：
     - 发布表单：上传视频文件 + 标题 + 学习方向（农业/电商/手工）+ **课程简介/知识点要点（必填文本：课程展示摘要 + AI 出题输入）** + 内容标签（如"荔枝/龙眼/直播话术"，多选）；
     - AI 课后测验配置（可选开启）：开启 → AI 依据课程简介自动生成 3~5 道选择题/判断题 → 教师**预览可修改**（改题干/选项/删题）→ 保存题库；关闭则无测验；
     - 提交审核 → 状态流转：
       - **待审核**：学员端不可见；此状态下教师可直接编辑全部内容（保持待审核）；
       - **审核通过** → 自动上架：出现在对应方向技能模块课程区块 + 学员端课程聚合页 + 推荐池；02 通知教师；
       - **审核驳回** → 02 通知教师（附审核意见）→ 修改后重新提交（重新进入待审核）；
       - **已上架 → 下架**（教师操作）：学员端即时不可见；可重新上架（重新审核）；
       - **编辑已上架课程**（改标题/换视频/改简介等）→ 重新进入待审核，审核期间学员端不可见（等同临时下架）；
     - 课程列表管理：按方向/状态（待审核/已上架/已驳回/已下架）筛选查看本人全部课程。
  2. 教学公告：
     - 发布/编辑教学通知公告（标题+内容）→ 经 02 群发全体学员；公告历史可查。
  3. 答疑互动：
     - 答疑互动区 = 课程视频与非遗视频的评论区 → 教师查看学员提问留言 → 回复（多轮可续）；
     - 教师回复在学员端评论区标注"教师回复"。
  4. 数据看板与 AI 学情报告：
     - 统计卡片（聚合数据，无学员明细档案）：
       - 学员总数（平台注册学员）；
       - 平均进度 = ∑(学员进度) ÷ 学员数；学员进度 = 该学员在自选方向下已完成课程数 ÷ 该方向已上架课程总数（**观看进度 ≥80% 记为完成**）；
       - 完成率 = 进度 100% 学员数 ÷ 学员总数；
       - 测验参与与通过情况（测验作答人次、平均分）；
       - 按学习方向分组查看（农业/电商/手工/综合）；
     - AI 学情报告：触发生成 → 内容三部分：进度分析、方向对比、风险预警（如长期零进度学员提示）→ 报告保存可回看；
     - AI 不可用 → 报告生成提示暂不可用，统计卡片不受影响。
  5. 消息：教师 ↔ 学员私信、接收系统通知与公告（能力来自 02）。
- 边界：不含学员档案管理（学员增删改查、班级/方向指派不做；方向学员自选）；不含作业/考勤（本期剔除）；不含课程定价、售卖；课程必须经审核，无直接发布通道；不含学员端功能。
- 数据触点：读写 课程视频（含标题、课程简介、标签、测验题库、审核/上下架状态）、教学公告、课程评论；读 学员学习统计（聚合：观看进度/测验成绩/方向分组）、学习行为；读写 AI 学情报告记录。
- 验收标准：
  1. 课程发布表单校验（简介必填等）；AI 测验生成-预览-修改-保存链路正确；
  2. 状态流转全分支验证：待审核可编辑、通过上架（三处可见）、驳回通知+重提、下架即时生效、编辑已上架触发重审且期间不可见；课程列表按状态筛选正确；
  3. 公告群发学员；评论区教师回复带标识；
  4. 统计口径验证（进度 ≥80%、完成率、平均进度、测验维度、方向分组）；AI 学情报告三部分齐全，AI 不可用有提示且统计可用。
- 依赖：01、02、11（课程审核）、外部 AI 服务（测验出题+学情报告）。

### 09-企业工作台

- 职责：职位发布与管理（需审核）、求职申请处理（筛选/状态/技能档案查看）、求职沟通、数据看板。
- 角色：企业是主角。
- 核心流程：
  1. 职位发布与管理：
     - 发布：填写标题/薪资/地点/类别/描述 → 提交 → **待审核**（学员端不可见；企业端标识"待审核"）→ 分支：
       - 审核通过 → 上架（企业端标识"已通过"），学员可投递；02 通知企业；
       - 审核驳回 → 02 通知企业（附审核意见）→ 修改后重新提交；
     - 编辑：待审核职位可直接编辑（保持待审核）；**已上架职位被编辑 → 重新进入待审核，学员端即时不可见**（等同临时下架），再次通过后恢复上架；
     - 删除：确认删除 → 学员端立即不可见 → 分支处理求职申请：未处理申请自动关闭并 02 通知相关学员（"岗位已关闭"）；已处理申请保留为历史记录；
     - 职位列表：按审核状态（待审核/已通过/已驳回）筛选查看本企业全部职位。
  2. 求职申请处理：
     - 申请列表：显示学员姓名、投递岗位、投递时间、当前状态；
     - **筛选排序**：按职位、状态（待处理/已查看/意向沟通/不合适）、投递时间筛选与排序；
     - 查看申请详情：含学员结构化简历 + **附带的技能档案**（学员未附带则仅简历）；
     - 标记状态：已查看/意向沟通/不合适（可**随时改标**，以最新状态为准，每次变更经 02 通知学员）；状态标记为可选操作，不强制；
     - 私信沟通：对投递学员发起私信（能力来自 02，范围=本企业收到投递的学员）。
  3. 数据看板（仅本企业数据）：
     - 在招职位数 = 本企业已上架职位总数；
     - 收到简历数 = 本企业累计收到的申请总数（含已处理）。
- 边界：不含农产品求购信息（看板统计不含求购项）；不含人才库搜索与主动邀约（只处理主动投递）；不含入职/签约/面试安排。
- 数据触点：读写 职位（含审核状态）、求职申请（状态）；读 简历、技能档案（学员附带部分）；读 本企业统计数据。
- 验收标准：
  1. 职位状态流转全分支：发布待审核、通过上架（学员可投递）、驳回通知+重提、待审核可编辑、已上架编辑触发重审且期间学员端不可见、删除后学员端立即不可见+未处理申请关闭通知；
  2. 申请列表筛选排序（职位/状态/时间）正确；
  3. 申请详情含简历与附带技能档案；状态标记/改标后学员端"我的投递"同步更新且通知送达；
  4. 看板口径（在招职位数=已上架数、收到简历数=累计申请数）验证正确，且不含其他企业数据。
- 依赖：01、02、11（职位审核）。

### 10-政务工作台

- 职责：政策（含创业支持类别）与新闻资讯发布管理、数据看板（**不含用户信息与培训数据**）。
- 角色：政府是主角。
- 核心流程：
  1. 政策管理：
     - 发布：填写标题/内容/类别（七类：补贴、电商、非遗、培训、认证、综合、**创业支持**）→ 发布**即上架**（学员端按类别立即可见）→ 触发订阅推送（该类别订阅学员经 02 收到通知）；
     - 下架：学员端不可见，数据保留；重新上架：恢复可见；删除：彻底移除；
     - 政策列表：按类别/状态（在架/下架）筛选管理。
  2. 新闻管理：
     - 发布：填写标题/内容/类别（三类：新闻、灾害预警、政策更新）→ 发布即对学员可见；删除即不可见（新闻无单独上下架操作）。
  3. 数据看板（只读）：
     - 就业数据：在招岗位数（全平台已上架）、累计投递量；
     - 内容生产数据：政策总数（在架/下架分列）与累计点击浏览量、新闻总数与累计点击浏览量；
     - **不展示**：总用户数、按角色用户分布、学员地区/方向分布等用户类指标；课程数、学习行为量、进度/完课率等培训类指标（用户类与培训类数据仅超管可见）。
- 边界：不含政策发布前的二级审批流（发布即上架）；不含补贴线上申领与办理；数据看板只读、不含数据导出；不含用户信息与培训数据查看；不含证书数据。
- 数据触点：读写 政策（含状态）、新闻资讯；读 业务聚合统计（就业/内容生产+浏览量，不含用户与培训数据）。
- 验收标准：
  1. 政策发布即上架、学员端七类可见；下架即不可见、重新上架恢复、删除彻底移除；发布触发订阅推送；
  2. 新闻发布即可见、删除即不可见；三类正确分类展示，灾害预警可被学员看到；
  3. 看板指标正确且**不出现任何用户类与培训类指标**。
- 依赖：01、02（订阅推送）；统计来源于 03~09（读，不含用户明细与培训数据）。

### 11-系统管理后台

- 职责：**超级管理员**拥有全平台所有数据管理权限：全量看板、账号与权限管理（含密码重置）、积分规则配置、全平台内容管理、完整兑换记录查询；**普通管理员**为内容运维：内容审核、违规评论与举报处理、预置内容维护、奖品库与兑换履约管理、内容运维看板。用户敏感数据对普通管理员不可见（履约单按口径开放业务字段视图）。
- 角色：超级管理员与普通管理员双角色。
- 核心流程（按角色分组）：

  **超级管理员流程：**
  1. 数据看板（全量）：总用户数（按角色分类）、学员数、岗位数（已上架）、课程数（已上架）、政策/新闻总数与累计点击浏览量、待审核数（三类先审后发内容分列）、积分/兑换概况（积分发放总量、兑换笔数、待发放履约数）等全平台指标。
  2. 账号与权限管理：按角色筛选、关键词搜索 → 查看用户列表/详情 → 操作分支：
     - 禁用账户 → 该用户立即无法登录（01 登录拦截），数据保留；
     - 启用账户 → 恢复登录；
     - 创建账户 → 为企业/政府/普通管理员/超级管理员角色创建账户并分配初始用户名/密码（这四类角色不开放自助注册）；
     - **重置密码** → 用户忘记密码场景：重置为初始密码 → 02 通知该用户（或线下告知）→ 用户以初始密码登录后自行修改；
     - 不提供账户物理删除（避免业务数据级联丢失）；首个超管初始账户由系统预置。
  3. 积分规则配置：修改"学习行为→积分"折算比率、每日获取上限、**积分有效期**（默认永久/按自然年）→ 保存后学员端即时生效（有效期变更只影响此后到期计算，不追溯已发积分）。
  4. 全平台数据管理：对任何数据执行查看、编辑、下架、删除——包括政府发布的政策/新闻（纠错、下架）、课程/职位/非遗教学视频/评论、预置内容。
  5. 兑换记录查询：完整兑换记录（含用户身份与联系方式明细、积分流水）。

  **普通管理员流程（内容运维）：**
  6. 内容审核（先审后发三类）：审核**课程视频、职位、非遗教学视频** → 分支：
     - 通过 → 内容即时上架/展示（课程进入对应模块区块+聚合页+推荐池；职位学员端可见可投递）；
     - 驳回 → 填写审核意见 → 经 02 通知提交者（教师/企业），被驳回内容不出现在学员端，提交者修改后可重新提交；
  7. 评论监管（即时发布+事后监管）：视频评论区巡查 → 删除违规评论（静默删除，不通知被删者，删除后学员端即不再展示）；
     - **举报处理**：查看学员举报队列（被举报评论+举报理由）→ 分支：确认违规 → 删除评论并记录处理结果；驳回举报 → 评论保留，记录处理结果；
     - 查看学员意见反馈列表。
  8. 预置内容维护：农产品目录、农时日历数据、病虫害知识库、非遗技艺内容（介绍/步骤/材料指南）、成功案例、AI 学伴功能说明知识库 → 增删改 → 更新后学员端即时生效。
  9. 奖品库与兑换履约管理：
     - 奖品维护：名称、所需积分、库存 → 上架/下架 → 学员端积分商城同步变化；
     - 履约单处理：查看履约队列（**业务字段视图：学员编号/昵称 + 奖品 + 状态，不含联系方式明细**）→ 分支：
       - 执行发放（待发放→已发放）→ 02 通知学员；
       - 取消（待发放→已取消：积分回退、库存回滚）→ 02 通知学员；
       - 核销（已发放→已核销，学员确认收货或管理员核销）；
  10. 数据看板（内容运维视角）：待审核数（三类分列）、已上架课程数、在架职位数、评论/举报处理量、奖品库存与**待发放履约数**。**不展示任何用户统计**。

- 边界：
  - **普通管理员**：不含账号管理（用户数据不可见、无入口：用户列表/详情/完整兑换记录均无权限；履约单仅业务字段视图）；不含积分规则配置；不含政策/新闻编辑管理（政府自治，超管保留纠错权）；不直接生产业务内容（课程/职位由教师/企业发布）。
  - **超级管理员**：全平台数据管理权限不受上述限制；业务内容常规生产仍由教师/企业/政府完成，超管定位管理与纠错。
- 数据触点：
  - 超管：读写 用户账户（状态/密码重置）、积分规则、全平台内容（政策/新闻/课程/职位/资源/评论/预置内容）；读 完整兑换记录、全平台统计（含用户统计与浏览量）。
  - 普通管理员：读写 审核记录（三类先审后发内容）、举报队列、预置内容、奖品库、履约单（业务字段视图）；读 内容运维统计（无用户统计）。
- 验收标准：
  1. 普通管理员登录后无账号管理入口，无法查看用户列表/用户详情/完整兑换记录；履约单仅业务字段视图（无联系方式）；
  2. 超管全操作链验证：创建/禁用/启用账户、重置密码后用户可用初始密码登录、编辑政策/新闻等全平台数据、积分规则（比率/上限/有效期）修改即时生效；
  3. 三类先审后发内容通过/驳回+通知正确；评论监管删除即不展示；举报处理闭环（确认删除/驳回举报）且处理量入看板；
  4. 奖品上下架同步；履约流转（发放/取消/核销）正确，取消时积分回退+库存回滚+通知；兑换记录仅超管可见完整版；
  5. 预置内容（含 AI 学伴知识库）维护即时生效；
  6. 普管看板仅内容运维指标（含待发放履约数），无用户统计。
- 依赖：01、02；被 03、05、06、07、08、09、12 依赖。

### 12-AI 学伴

- 职责：全站悬浮 AI 学伴：**平台使用答疑**（各功能怎么用）+ **学习问题引导**（指路对应模块深入处理）+ 常见问题自答；支持三大方言语音提问。
- 角色：**全角色可用**（学员/教师/企业/政府门户均可唤起）；**后台管理端（超级管理员/普通管理员门户）不展示 AI 学伴入口**。
- 核心流程：
  1. 唤起：用户 → 点击页面悬浮球（全站常驻，管理端除外）→ 展开对话面板 → 文字输入或语音提问（语音识别转文字；识别失败 → 提示重试或改用文字）；
  2. 意图判定与应答（AI）：
     - **平台使用类**（"怎么投简历""积分怎么算""怎么订阅政策"）→ 基于功能说明知识库（11 预置维护）直接作答 → 可**引导跳转**对应模块（应答附"去查看"跳转按钮）；
     - **学习类问题**（"荔枝什么时候套袋""荔枝蒂蛀虫怎么防"）→ 给出要点式回答 + 引导至对应模块深入处理（如"进入农业技能→AI 问答继续追问"）；
     - **超出范围**（业务代办类如"帮我投简历/帮我兑换"）→ 拒绝代办，建议使用对应功能入口或联系管理员；
  3. 会话记录：学伴会话按用户保存，可回看（仅本人可见）；
  4. AI 不可用 → 提示"AI 服务暂时不可用"。
- 边界：不做业务代办（不代投递/不代兑换/不代审核/不代发消息）；深度学习问题引导至专属模块而非自行长答（避免与 03 问答重复）；后台管理端不展示；方言语音仅提问侧（回答以文字为主，可配 TTS）。
- 数据触点：读写 学伴会话记录；读 功能说明知识库（11 预置）、用户账户（当前用户）。
- 验收标准：
  1. 悬浮入口在学员/教师/企业/政府门户全站可用，管理端（超管/普管）不出现；
  2. 三类意图分支验证：使用类作答+可跳转、学习类要点+引导模块、代办类拒绝并指路；
  3. 文字与语音提问均可用，语音识别失败有提示；会话记录可回看；AI 不可用统一提示。
- 依赖：01-账户与门户、11（功能说明知识库维护）、外部 AI 大模型服务。
