# CSS 语义类名例外

状态：T13 收口后的保留项，只有确实无法静态表达或属于第三方契约的项保留。

## 保留的兼容类名

- 页面静态类名已切换到语义名，模板和活动 CSS 不再保留旧前缀别名。
- 共享基础类名是稳定产品契约，不进入前缀映射：`btn`、`card`、`table`、`tag`、
  `modal`、`field`、`container`、`section-*`、`is-*`、`has-*`。
- Font Awesome、`model-viewer` 和第三方注入类不参与重命名。

## 动态类名

下列动态值继续由数据驱动，不强行拼成静态选择器：

- `is-${kind}`、`is-${status}`、`type-${type}`、`msg-tag-${type}`
- `rec-${status}`、`is-color-${index}`、`statusClass(...)`
- `category.key`、`item.icon`、`message.role` 等来自后端或图标映射的类

这些值由状态属性、语义容器和组件 scoped 样式共同承载；删除前必须有静态或运行时
引用证据。无法安全静态化的动态前缀继续保留，并在 T13 之后作为稳定行为契约维护。

## 受限内联绑定

以下数据驱动的数值样式保留为受限 `:style` 绑定，因为值来自接口数据或运行时计算：

- 进度条宽度、评分比例和图表柱高
- 农时阶段颜色、任务颜色和动态分类色
- 日历网格的 `--phase-color`

静态装饰样式不得新增内联绑定。新增动态值优先写成 CSS 自定义属性，再由 CSS 消费。
