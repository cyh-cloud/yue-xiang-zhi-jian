## Global Constraints

- 只允许 `active` 的 `student` 会话访问 07 API 和前端路由；身份只取 `load_session()`，不信任客户端 `student_id`。
- 岗位读取只使用 09 `JobPositionProvider`：`list_published_positions()` 和 `get_published_position(job_id)`；不读取 09 表。
- 投递写入只使用 09 `JobApplicationIntakeProvider.submit_application(...)`；07 不读取或写入 `job_applications`。
- 状态读取只使用 09 新增的 `JobApplicationStatusProvider.list_student_applications(...)` 和 `get_student_application(...)`；09 是状态事实的唯一权威。
- 07 定义技能档案聚合、逐项可见范围和快照契约；03/04/05 只作为成果生产方，函数不得回写或复制。
- 技能档案默认全部不可见，只有明确勾选项能进入投递快照；未附带时向 09 传 `None`。
- 投递快照在成功调用 09 provider 时冻结；后续简历、可见范围或来源成果变化不得回写历史申请。
- 唯一 AI 调用点为 `resume_optimize`；AI 不可用统一提示“AI 服务暂时不可用”，手动简历、岗位、投递、状态和收藏不受影响。
- 07 不调用 02 发送投递通知；申请投递、状态变化和岗位关闭通知均归 09。
- 不做农产品求购、线上面试、电子签约、入职管理、企业人才库、主动邀约和投递撤回。
- 旧系统根目录 `app.py`、`database.py` 和旧 HTML 页面禁止参考、导入、复制或迁移。
- 路由 kebab-case，Python snake_case，前端变量/函数 camelCase；每个任务先写失败测试，再最小实现，运行定向测试后提交。

## Confirmed Decisions

- 简历只有至少一个非空结构化区块且成功保存后，才算通过投递前置校验。
- AI 只产生建议和有或无的完整改写稿；没有改写稿时不允许自动替换。采纳是显式原子操作，放弃保持原稿。
- 简历采纳后旧版本仅保留为内部修订和审计数据，本期不提供用户历史回退入口。
- 技能档案按 `item_id` 逐项勾选；缺失可见记录等于不可见。
- 四类技能成果为 `live_script`、`simulation_training`、`quiz_score`、`learning_record`。
- 推荐岗位只以 `job.category_id` 与学员活动 `job` 标签精确匹配；学习成果只作为 90 天活跃度和最近时间排序信号。
- 岗位从 provider 消失时，收藏按不可用处理并显示“岗位已关闭”；若重新出现则恢复最新岗位信息。
- 已处理申请关闭后保留人工状态并附加关闭标识；待处理申请关闭后有效状态为 `closed`。

## 投递三分支校验的测试口径

| 分支 | 前置数据 | 请求结果 | 持久化断言 | 通知断言 | 用户可见文案 |

| 无简历 | `resumes.version=0` 或三区块全空 | HTTP 409，`code=resume_required` | 09 intake 调用次数为 0 | 企业通知增量为 0 | “请先创建并保存简历” |
| 重复投递 | 09 status provider 已有同一 `(student_id, job_id)` | HTTP 409，`code=already_applied` | 09 intake 调用次数为 0 | 企业通知增量为 0 | “已投递该岗位” |
| 岗位不可见 | `get_published_position()` 返回 `None` | HTTP 404/409，`code=job_unavailable` | 09 intake 调用次数为 0 | 企业通知增量为 0 | “岗位已关闭或暂不可投递” |
| 成功 | 已保存简历 + 无重复 + 职位可见 | HTTP 201 | provider 收到精确快照和稳定幂等键 | 仅 09 触发一次 | 跳转“我的投递” |

竞态测试：

1. 第 1 次状态预检返回空，随后 provider 创建成功。
2. 同一幂等键重试返回原申请。
3. 第二次状态预检发现重复时不得调用 intake。
4. 超时重试后的申请数和通知数均保持 1。

def _normalize_items(
    value,
    required_fields,
    optional_fields,
    field_name,
):
    if not isinstance(value, list):
        raise JobMatchingValidationError(f"{field_name} 必须是列表")
    normalized = []
    for item in value:
        if not isinstance(item, dict):
            raise JobMatchingValidationError(f"{field_name} 条目格式不正确")
        normalized_item = {}
        for key in required_fields:
            text = str(item.get(key, "")).strip()
            if not text:
                raise JobMatchingValidationError(
                    f"{field_name}.{key} 不能为空",
                    details={f"{field_name}.{key}": "不能为空"},
                )
            normalized_item[key] = text
        for key in optional_fields:
            normalized_item[key] = str(item.get(key, "")).strip()
        normalized.append(normalized_item)
    return normalized


def _normalize_payload(payload: dict) -> dict:
    if not isinstance(payload, dict):
        raise JobMatchingValidationError("简历格式不正确")
    education = _normalize_items(
        payload.get("education_experiences", []),
        EDUCATION_REQUIRED_FIELDS,
        EDUCATION_OPTIONAL_FIELDS,
        "education_experiences",
    )
    work = _normalize_items(
        payload.get("work_experiences", []),
        WORK_REQUIRED_FIELDS,
        WORK_OPTIONAL_FIELDS,
        "work_experiences",
    )
    raw_skills = payload.get("skills", [])
    if not isinstance(raw_skills, list):
        raise JobMatchingValidationError("skills 必须是列表")
    skills = []
    for skill in raw_skills:
        text = str(skill).strip()
        if text and text not in skills:
            skills.append(text)
    if not education and not work and not skills:
        raise JobMatchingValidationError(
            "至少填写一个简历区块",
            details={"resume": "至少填写一个简历区块"},
        )
    return {
        "education_experiences": education,
        "work_experiences": work,
        "skills": skills,
    }

def optimize_resume(student_id: int, expected_version: int) -> dict:
    resume = get_resume(student_id)
    if resume["version"] != expected_version:
        raise ResumeConflictError("简历版本已变化")
    context = {
        "education_experiences": resume["education_experiences"],
        "work_experiences": resume["work_experiences"],
        "skills": resume["skills"],
    }
    try:
        result = get_ai_client().complete_json(
            build_ai_messages("resume_optimize", context),
            call_point="resume_optimize",
        )
    except AiUnavailableError as error:
        raise AiUnavailableError(AI_UNAVAILABLE_MESSAGE) from error
    try:
        normalized = _normalize_ai_result(result)
    except (JobMatchingValidationError, TypeError, ValueError) as error:
        raise AiUnavailableError(AI_UNAVAILABLE_MESSAGE) from error
    offer = {
        "offer_id": f"resume-offer-{uuid.uuid4().hex}",
        "base_version": expected_version,
        "suggestions": normalized["suggestions"],
        "rewritten_resume": normalized["rewritten_resume"],
        "status": "offered",
        "created_at": _now_iso(),
    }
    _insert_offer(student_id, offer)
    return offer


def adopt_resume_optimization(
    student_id: int,
    offer_id: str,
    expected_version: int,
) -> dict:
    offer = _owned_offer(student_id, offer_id)
    if offer["status"] != "offered":
        raise JobMatchingValidationError("优化稿已处理")
    rewritten = offer["rewritten_resume"]
    if rewritten is None:
        raise JobMatchingValidationError("该结果仅包含建议，不能自动替换")
    current = get_resume(student_id)
    if current["version"] != expected_version:
        raise ResumeConflictError("简历版本已变化")
    if offer["base_version"] != expected_version:
        raise ResumeConflictError("优化稿已过期")
    saved = _save_normalized_resume(
        student_id,
        rewritten,
        expected_version,
        offer_id=offer_id,
    )
    return saved

def _parse_iso(value: str) -> datetime:
    return datetime.fromisoformat(value.replace("Z", "+00:00"))


def _recommend_jobs(student_id: int, jobs: list[dict]) -> list[dict]:
    preferences = get_profile_preferences(student_id)
    job_tag_ids = set(preferences["interest_tag_ids"])
    outcomes = list_skill_outcomes(student_id)
    cutoff = datetime.now(ZoneInfo("Asia/Shanghai")) - timedelta(days=90)
    recent = [
        outcome
        for outcome in outcomes
        if _parse_iso(outcome["occurred_at"]) >= cutoff
    ]
    latest_learning_at = max(
        (item["occurred_at"] for item in recent),
        default=None,
    )
    candidates = []
    for job in jobs:
        match_count = int(job["category_id"] in job_tag_ids)
        candidates.append(
            {
                **job,
                "category_match_count": match_count,
                "recent_learning": bool(recent),
                "latest_learning_at": latest_learning_at,
            }
        )
    candidates.sort(
        key=lambda job: (
            0 if job["category_match_count"] else 1,
            0 if job["recent_learning"] else 1,
            -(int(_parse_iso(job["latest_learning_at"]).timestamp())
              if job["latest_learning_at"] else 0),
            -int(_parse_iso(job["published_at"]).timestamp()),
            str(job["job_id"]),
        )
    )

export const useJobMatchingStore = defineStore('jobMatching', {
  state: () => ({
    resume: null as StudentResume | null,
    optimizationOffer: null as ResumeOptimizationOffer | null,
    skillProfile: null as SkillProfile | null,
    jobs: [] as JobMatchingJob[],

    error: '',

    fieldErrors: {} as ApiFieldErrors

  actions: {
    async loadResume() {
      const response = await apiFetch<{ success: true; resume: StudentResume }>(
        '/api/job-matching/resume'
      )
      this.resume = response.resume
      return this.resume
    },
    async submitApplication(jobId: string, attachSkillProfile: boolean) {
      try {
        const response = await apiFetch<{
          success: true
          application: StudentApplication
        }>(
          `/api/job-matching/jobs/${encodeURIComponent(jobId)}/applications`,
          {
            method: 'POST',
            body: JSON.stringify({
              attach_skill_profile: attachSkillProfile
            })
          }
        )
        return response.application
      } catch (error) {
        this.captureError(error)
        return null
      }
    }
  }
})

captureError(error: unknown, fallback = '就业对接请求失败') {
  if (error instanceof ApiError) {

    this.fieldErrors = error.errors
    return
  }
  this.error = error instanceof Error ? error.message : fallback

  this.fieldErrors = {}
}
