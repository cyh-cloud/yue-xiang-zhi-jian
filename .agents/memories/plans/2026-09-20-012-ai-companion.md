## Global Constraints

- Feature 分支固定为 `v2/lixKRT/012-ai-companion`，worktree 固定为 `.worktrees/012-ai-companion`。
- 后端模块目录固定为 `backend/app/ai_companion/`；Python snake_case，路由 kebab-case。
- 旧系统根目录 `app.py`、`database.py` 和旧 HTML 不得读取、导入或迁移。
- AI 学伴仅允许 `student`、`teacher`、`enterprise`、`government`；`super_admin`、`admin` 必须隐藏入口并由 API 拒绝。
- 前端显隐只看当前会话用户 `role`，不得读取路由 `name/path/meta.roles` 决定是否显示。
- 显式业务代办先走规则拒绝；其余问题由 AI 分类为 `platform_usage`、`learning_question`、`out_of_scope`。
- 平台使用类只能基于 11 知识条目回答；“去查看”直接使用 `jump_target`，不维护第二张业务跳转表。
- 学习类最多 5 条要点，必须引导到现有模块，不接管 03 等专业问答。
- AI 服务失败统一“AI 服务暂时不可用”；知识为空、无匹配或来源不可用统一“暂无法回答，请稍后再试”；ASR 不可识别统一“未能识别，请重说或改用文字”。
- ASR 唯一底层路径是 `app.agri_skills.ai_client.get_ai_client().transcribe(audio, filename, call_point="speech_to_text")`；不得新增客户端或模型配置。
- 知识 provider 唯一槽是 `assistant_feature_knowledge_provider`；11 是 Protocol、占位和 set/get 的唯一权威，12 只导入/重导出并消费。
- 会话仅本人可见；保留最近 180 天、最多 100 个会话、每会话最多 200 条消息；不保存原始或合成音频。
- 每个行为先写失败测试，再写最小实现；任务结束运行定向测试并提交。

    conversation_id TEXT PRIMARY KEY,
    user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    title TEXT NOT NULL CHECK (length(trim(title)) > 0),

    jump_target TEXT,
    client_request_id TEXT,
    created_at TEXT NOT NULL

entries = get_assistant_feature_knowledge_provider().list_entries(
    enabled_only=True
)

It validates every entry. If any entry has unknown or invalid structure, return
an empty list for the whole source so the user receives the knowledge-empty
message instead of an answer assembled from a partially trusted payload. If
the provider raises, raise `AiCompanionKnowledgeUnavailableError`.

filter out entries whose normalized `is_enabled` is false. Do not trust the
producer to honor the argument.

`title/body/feature_key` into lowercase alphanumeric tokens and CJK bigrams,

Content-Type: multipart/form-data

text = get_ai_client().transcribe(

Rules:

- No dialect code is sent to ASR.
- Empty/missing audio and `AgriValidationError` return 422 with “未能识别，请重说或改用文字”.
- `AiUnavailableError` returns 503 with “AI 服务暂时不可用”.
- The frontend uses `VoiceInputButton`, keeps recognized text editable, and does not submit until the user confirms.
- The 003 student-only route is not called by 12.
