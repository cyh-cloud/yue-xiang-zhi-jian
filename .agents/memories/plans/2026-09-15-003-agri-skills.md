# 03-农业技能 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 03-农业技能子系统，包括农时日历、农产品订阅提醒、语音/文字农技问答、点选式病虫害诊断、复诊与自测闭环、农业课程学习进度及 AI 课后测验。

**Architecture:** 后端在 `backend/app/agri_skills/` 内建立独立领域包，通过 provider 协议消费 11 的预置内容和 08 的课程数据，通过现有 02 `MessagingSourceProvider` 暴露农产品订阅受众，通过可替换 AI gateway 统一执行请求白名单、模型调用和降级。前端在 `frontend/src/agri-skills/` 下建立独立页面与 Pinia store；共享层只扩展类型、SSE 客户端、路由和学员门户入口，不复制 01/02 能力。

**Tech Stack:** Python 3.12、Flask、sqlite3、httpx、uv、unittest、Vue 3、Vite、Pinia、Vue Router、Vitest、Vue Test Utils、lucide-vue-next。

**Spec:** `specs/003-agri-skills/spec.md`

## Global Constraints

- 本模块只允许已登录、会话状态为 `active` 的学员访问；账户、会话和角色路由复用 01。
- 兴趣标签只读复用 01；不得创建标签目录、标签编辑或第二份学员偏好。
- 农事提醒只经 02 消息中心发送；不得创建第二套通知、未读或推送机制。
- 农业课程来自 08 的已上架课程和课程标签；03 不得创建课程、审核或题库编辑能力。
- 农产品目录、农时日历和病虫害知识库由 11 提供；11 未实现时只读使用明确标记的占位 provider。
- 仅农技问答允许降级本地病虫害知识库；诊断、自测、课程测验判分均不降级。
- AI 服务不可用统一提示“AI 服务暂时不可用”；语音识别失败统一提示“未能识别，请重试或改用文字输入”。
- AI 请求必须通过调用点字段白名单；不得发送账户标识、联系方式、凭证、其他学员数据或无关历史。
- 达到五轮时必须停止追问并生成标注“信息有限”的结论。
- 课程进度按最远有效播放位置除以视频总时长向下取整；达到 80% 记为完成，状态只前进不回退。
- 已完成课程不得进入推荐池；推荐顺序为标签交集数、未完成观看、最近观看时间、有效进度、上架时间、课程稳定标识。
- 所有后端代码位于 `backend/`；所有前端代码位于 `frontend/`。
- 旧系统 `app.py`、`database.py` 和根目录旧 HTML 页面禁止读取、导入、复制或迁移。
- 路由 kebab-case、Python snake_case、前端 camelCase；每个任务先失败测试、再最小实现、再验证、再提交。

## AI 调用点与降级矩阵

| 调用点 | 失败表现 | 降级行为 | 前端提示文案 |
| --- | --- | --- | --- |
| 语音识别 `speech_to_text` | 噪音、取消、空结果、识别服务不可用 | 不检索本地知识库；保留文字输入；服务恢复前允许重试 | 识别失败：`未能识别，请重试或改用文字输入`；服务失败：`AI 服务暂时不可用` |
| 农技问答回答 `qa_answer` | 请求失败、流在首块前失败、流中断且无法完成 | 规范化和排序本地病虫害知识库；有唯一最高匹配时替换为离线答案，无匹配提示稍后重试 | 命中：`离线知识库回答`；未命中：`暂无法回答，建议稍后再试` |
| 问答追问建议 `qa_followups` | 回答完成但建议调用失败、返回非三项 | 不单独降级；沿用当前问答的回答模式，不生成建议 | AI 建议失败时显示 `AI 服务暂时不可用`；离线回答不显示该提示，仅不展示建议 |
| 诊断追问与结论 `diagnosis_turn` | 请求失败、状态缺失或非法、返回结构不完整 | 不降级；保存点选、回答和当前轮次，恢复后继续 | `AI 服务暂时不可用` |
| 诊断自测生成 `selftest_generate` | 首次或第二次结构无效、服务不可用 | 不降级；最多生成两次，仍失败则丢弃全部无效题目 | `AI 服务暂时不可用` |
| 诊断自测判分与讲解 `selftest_grade` | 请求失败、返回缺题或缺讲解 | 不降级；保留自测和原诊断，允许稍后重提 | `AI 服务暂时不可用` |
| 课程测验判分与讲解 `course_quiz_grade` | 请求失败、缺少逐题结果 | 不降级；课程、进度和历史成绩不变 | `AI 服务暂时不可用` |

课程测验题库生成和保存属于 08，不是 03 的 AI 调用点。03 只消费 08 题库并提交作答。

Create `backend/app/agri_skills/ai_client.py`:

```python
from __future__ import annotations

from collections.abc import Iterator

from flask import Flask, current_app

from app.agri_skills.errors import AiUnavailableError


class NullAiClient:
    def stream_chat(self, messages: list[dict], *, call_point: str) -> Iterator[str]:
        raise AiUnavailableError("AI service is not configured")

    def complete_json(self, messages: list[dict], *, call_point: str) -> dict:
        raise AiUnavailableError("AI service is not configured")

    def transcribe(self, audio: bytes, filename: str, *, call_point: str) -> str:
        raise AiUnavailableError("AI service is not configured")


def set_ai_client(app: Flask, client) -> None:
    app.extensions["agri_ai_client"] = client


def get_ai_client():
    return current_app.extensions.get("agri_ai_client", NullAiClient())
```

```python
class CompositeMessagingSourceProvider:
    def __init__(self, providers: list) -> None:
        self.providers = list(providers)

    def has_application_relationship(self, student_id: int, enterprise_id: int) -> bool:
        return any(
            provider.has_application_relationship(student_id, enterprise_id)
            for provider in self.providers
        )

    def list_applied_enterprise_ids(self, student_id: int) -> list[int]:
        return sorted({
            item
            for provider in self.providers
            for item in provider.list_applied_enterprise_ids(student_id)
        })

    def list_applicant_student_ids(self, enterprise_id: int) -> list[int]:
        return sorted({
            item
            for provider in self.providers
            for item in provider.list_applicant_student_ids(enterprise_id)
        })

    def list_policy_subscriber_ids(self, category: str) -> list[int]:
        return sorted({
            item
            for provider in self.providers
            for item in provider.list_policy_subscriber_ids(category)
        })

    def list_product_subscriber_ids(self, product_key: str) -> list[int]:
        return sorted({
            item
            for provider in self.providers
            for item in provider.list_product_subscriber_ids(product_key)
        })


def register_messaging_source_provider(app: Flask, provider) -> None:
    current = app.extensions.get("messaging_source_provider")

    providers = [current, provider] if current is not None else [provider]
    set_messaging_source_provider(app, CompositeMessagingSourceProvider(providers))
```

```python
class OpenAiCompatibleAiClient:
    def __init__(self, *, api_url: str, api_key: str, model: str, timeout: float, transport=None):
        self.api_url = api_url
        self.api_key = api_key
        self.model = model
        self.timeout = timeout
        self.transport = transport

    def _client(self):
        if self.transport is not None:
            return httpx.Client(transport=self.transport, timeout=self.timeout)
        return httpx.Client(timeout=self.timeout)

    def stream_chat(self, messages: list[dict], *, call_point: str):
        if not self.api_url or not self.api_key:
            raise AiUnavailableError("AI service is not configured")
        with self._client() as client:
            with client.stream(
                "POST",
                self.api_url,
                headers={"Authorization": f"Bearer {self.api_key}"},
                json={"model": self.model, "messages": messages, "stream": True},
            ) as response:
                response.raise_for_status()
                for line in response.iter_lines():
                    if not line.startswith("data: "):
                        continue
                    payload = line[6:]
                    if payload == "[DONE]":
                        break
                    data = json.loads(payload)
                    content = data["choices"][0]["delta"].get("content", "")
                    if content:
                        yield content

    def complete_json(self, messages: list[dict], *, call_point: str) -> dict:
        if not self.api_url or not self.api_key:
            raise AiUnavailableError("AI service is not configured")
        with self._client() as client:
            response = client.post(
                self.api_url,
                headers={"Authorization": f"Bearer {self.api_key}"},
                json={"model": self.model, "messages": messages, "stream": False},
            )
            response.raise_for_status()
            content = response.json()["choices"][0]["message"]["content"]
            return json.loads(extract_json_object(content))

    def transcribe(self, audio: bytes, filename: str, *, call_point: str) -> str:
        raise AiUnavailableError("ASR endpoint is not configured")
```

```python
def _normalize_question(question: str) -> str:
    return re.sub(r"\s+", "", question.strip().lower())


def select_local_knowledge_entry(question: str) -> dict:
    normalized = _normalize_question(question)
    candidates = []
    for entry in get_preset_provider().list_pest_entries():
        fields = [
            entry["pest_name"],
            *entry["product_names"],
            *entry["symptoms"],
            *entry["aliases"],
        ]
        matches = [field for field in fields if _normalize_question(field) in normalized]
        if matches:
            candidates.append(
                {
                    "entry": entry,
                    "match_count": len(matches),
                    "matched_length": max(len(_normalize_question(item)) for item in matches),
                    "sort_order": int(entry["sort_order"]),
                }
            )
    if not candidates:
        raise AiUnavailableError("暂无法回答，建议稍后再试")
    candidates.sort(
        key=lambda item: (
            -item["match_count"],
            -item["matched_length"],
            item["sort_order"],
            item["entry"]["id"],
        )
    )
    return candidates[0]["entry"]
```

```python
def stream_qa_answer(conversation_id: int, question: str):
    try:
        chunks: list[str] = []
        messages = build_ai_messages("qa_answer", {"question": question})
        for chunk in get_ai_client().stream_chat(messages, call_point="qa_answer"):
            if chunk:
                text = str(chunk)
                chunks.append(text)
                yield {"type": "chunk", "content": text}
        answer = "".join(chunks)
        if not answer.strip():
            raise AiUnavailableError("AI service returned an empty answer")
        try:
            followups = get_ai_client().complete_json(
                build_ai_messages(
                    "qa_followups",
                    {"question": question, "answer": answer},
                ),
                call_point="qa_followups",
            )
            suggestions = [
                str(item).strip()
                for item in followups.get("suggestions", [])
                if str(item).strip()
            ]
        except AiUnavailableError:
            suggestions = []
        suggestion_error = (
            None if len(suggestions) == 3 else "AI 服务暂时不可用"
        )
        if suggestion_error:
            suggestions = []
        yield {
            "type": "complete",
            "answer": answer,
            "answer_mode": "ai",
            "suggestions": suggestions,
            "suggestion_error": suggestion_error,

    except AiUnavailableError:
        entry = select_local_knowledge_entry(question)
        yield {
            "type": "replace",
            "answer": format_local_answer(entry),
            "answer_mode": "local_kb",
            "suggestions": [],
```

```python
def _sse(event: str, payload: dict) -> str:
    return f"event: {event}\ndata: {json.dumps(payload, ensure_ascii=False)}\n\n"

    "/qa/conversations/<int:conversation_id>/messages/stream"
)
def stream_qa_message(conversation_id: int):
    session = _student_session()
    get_qa_thread(int(session["id"]), conversation_id)
    payload = request.get_json(silent=True) or {}
    question = str(payload.get("question", "")).strip()
    input_mode = str(payload.get("input_mode", "text"))
    if not question:
        return jsonify(success=False, errors={"question": "问题不能为空"}), 400

    def generate():
        chunks: list[str] = []
        for event in stream_qa_answer(conversation_id, question):
            if event["type"] == "chunk":
                chunks.append(event["content"])
                yield _sse("chunk", event)
```

```python
ALLOWED_AI_STATUSES = {"follow_up_required", "conclusion_ready"}


def start_diagnosis(user_id: int, session_id: int) -> dict:
    current = get_diagnosis(user_id, session_id)
    if current["status"] != "in_progress":
        return current
    if current["pending_question"]:
        return current
    try:
        result = _validate_ai_turn(
            get_ai_client().complete_json(
                build_ai_messages(
                    "diagnosis_turn",
                    {
                        "product_name": current["product"]["name"],
                        "affected_part": current["affected_part"],
                        "symptoms": current["symptoms"],
                        "round_no": 1,
                        "prior_questions": [],
                        "prior_answers": [],
                    },
                ),
                call_point="diagnosis_turn",
            ),
            forced_limited=False,
            context=current,
        )
    except AiUnavailableError:
        return {**get_diagnosis(user_id, session_id), "ai_error": "AI 服务暂时不可用"}
    return _store_ai_turn(user_id, session_id, result)


def _validate_ai_turn(
    payload: dict,
    *,
    forced_limited: bool,
    context: dict,
) -> dict:
    status = payload.get("status")
    if status not in ALLOWED_AI_STATUSES and not forced_limited:
        raise AiUnavailableError("AI 服务暂时不可用")
    if forced_limited:
        conclusion = payload.get("conclusion")
        if not isinstance(conclusion, dict) or not conclusion.get("cause") or not conclusion.get("treatment"):
            conclusion = {
                "cause": (
                    f"现有信息提示需要重点排查{context['product']['name']}"
                    f"{context['affected_part']}的"
                    f"{'、'.join(context['symptoms'])}问题"
                ),
                "treatment": (
                    "建议清理异常部位并持续观察，记录症状变化，"
                    "结合当地农技人员意见开展规范防治。"
                ),
            }
        return {
            "status": "conclusion_ready",
            "question": None,
            "conclusion": conclusion,
            "limited": True,
        }
    if status == "follow_up_required":
        question = str(payload.get("question", "")).strip()
        if not question:
            raise AiUnavailableError("AI 服务暂时不可用")
        return {
```

```typescript
export interface ApiStreamEvent<T> {
  event: string
  data: T
}

export async function apiStream<T>(
  path: string,
  options: RequestOptions,
  onEvent: (event: ApiStreamEvent<T>) => void
): Promise<void> {
  const baseUrl = import.meta.env.VITE_API_BASE_URL ?? ''
  const headers = new Headers(options.headers)
  headers.set('Accept', 'text/event-stream')
  if (options.body && !headers.has('Content-Type')) {
    headers.set('Content-Type', 'application/json')
  }
  const response = await fetch(`${baseUrl}${path}`, {
    ...options,
    headers,
    credentials: 'include'
  })
  if (!response.ok || !response.body) {
    const contentType = response.headers.get('content-type') ?? ''
    const payload = contentType.includes('application/json')
      ? await response.json()
      : null
    const payloadRecord =
      typeof payload === 'object' && payload !== null
        ? (payload as Record<string, unknown>)
        : null
    const message =
      typeof payloadRecord?.message === 'string'
        ? payloadRecord.message
        : `接口请求失败：${response.status}`
    const errors =
      typeof payloadRecord?.errors === 'object' &&
      payloadRecord.errors !== null &&
      !Array.isArray(payloadRecord.errors)
        ? Object.fromEntries(
            Object.entries(payloadRecord.errors as Record<string, unknown>).map(
              ([field, value]) => [field, String(value)]
            )
          )
        : {}
    const redirect =
      typeof payloadRecord?.redirect === 'string'
        ? payloadRecord.redirect
        : undefined
    const error = new ApiError(message, response.status, errors, redirect)
    if (response.status === 401 && redirect && sessionExpiredHandler) {
      await sessionExpiredHandler(error)
    }
    throw error
  }
  const reader = response.body.getReader()
  const decoder = new TextDecoder()
  let buffer = ''
  while (true) {
    const { value, done } = await reader.read()
    buffer += decoder.decode(value, { stream: !done })
    const blocks = buffer.split('\n\n')
    buffer = blocks.pop() ?? ''
    for (const block of blocks) {
      const event = block
        .split('\n')
        .find(line => line.startsWith('event: '))
        ?.slice(7)
      const data = block
        .split('\n')
        .find(line => line.startsWith('data: '))
        ?.slice(6)
      if (event && data) {
        onEvent({ event, data: JSON.parse(data) as T })
      }
    }
    if (done) {
      break
    }
  }
}
```
