# 采集域词汇

**来源**:
一个可独立采集、审核和调度的站点、接口或文件发布渠道。一个来源可以包含多个域名，但必须有唯一来源 ID。
_Avoid_: 网站、爬虫、数据源

**来源文档**:
一个来源的采集契约，记录入口、列表页、详情页、请求参数、字段、样本、限制和映射。
_Avoid_: 爬虫说明、采集笔记

**来源契约**:
所有来源文档共享的接口，规定记录字段、访问边界、证据、样本、详情 URL 和发布资格。
_Avoid_: 通用模板、来源说明汇总

**子资源**:
来源内访问边界或采集范围不同的页面、接口或域名，不单独形成来源 ID。
_Avoid_: 子来源、二级站点

**采集库**:
独立于粤乡智匠业务库的 SQLite 数据库，保存原始响应、来源内整理数据和跨来源标准实体。
_Avoid_: 爬虫库、临时库

**业务库**:
粤乡智匠当前使用的 SQLite 数据库，只保存展示、审核和运营所需的数据。
_Avoid_: 主库、正式库

**raw 层**:
采集库中保存原始响应和文件元数据的一层，用于回溯页面当时的内容。
_Avoid_: 缓存、原始表

**stage 层**:
采集库中按单个来源原始形状保存列表项、详情项和文件行的一层。
_Avoid_: 中间表、清洗表

**std 层**:
采集库中跨来源统一后的标准实体层，是转换器唯一读取的输入。
_Avoid_: 标准表、目标表

**转换器**:
把 std 层实体映射到业务库的组件，负责自然键、去重、冲突、人工字段保护、发布、批次和回滚。
_Avoid_: 导入脚本、同步器

**自然键**:
在多来源和多次采集中稳定识别同一条业务实体的字段组合。
_Avoid_: 主键、唯一键

**升级写入**:
按自然键存在则更新、不存在则插入的写入方式。
_Avoid_: upsert、覆盖写入

**详情 URL**:
能直接打开单条来源记录的页面地址，而不是站点首页或列表首页。
_Avoid_: 来源链接、原始链接

**访问等级**:
来源的访问状态，取值为 `public`、`login-required`、`robots-restricted` 或 `manual-only`。
_Avoid_: 权限、可见性

**来源优先**:
多来源冲突时按官方原始公告、官方查询系统、学术或官方机构、行业站、聚合站、UGC 的顺序裁决。
_Avoid_: 数据优先级

**人工字段保护**:
转换器不覆盖运营在业务库手工修改过的字段。
_Avoid_: 锁定字段、只读字段

**可教学标记**:
非遗项目是否具备足够教学步骤、视频或采购指南，可进入前台完整教学视图的标记。
_Avoid_: 上架、发布状态

**认证农产品**:
全国名特优新、特质农品、农业食品相关地理标志等具有官方认证或认定背景的产品目录条目。
_Avoid_: 农产品、作物

**认证类型**:
区分名特优新、特质农品和地理标志等目录口径的字段。
_Avoid_: 分类、标签

**子项**:
国家级非遗项目中按申报地区或单位统计的一条记录。3610 个子项聚合为 1557 个项目。
_Avoid_: 条目、项目

**项目编号**:
国家级非遗项目的官方编号，如 `Ⅰ-1`。
_Avoid_: 编码、编号

**手工技艺**:
粤乡智匠现有手工传承内容域，主要展示可教学的非遗项目和步骤。
_Avoid_: 非遗、技艺

**方言点**:
具有明确地区或调查点属性的方言记录单元。
_Avoid_: 方言、地区

**词条**:
方言点下的一条词形、释义、读音或例句记录。
_Avoid_: 短语、词汇

**受限来源**:
因 robots、登录、付费或授权不明而只能登记、不能自动采集正文的来源。
_Avoid_: 不可用来源、失败来源
