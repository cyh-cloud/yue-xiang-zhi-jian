# 来源契约

本文件是 14 份来源文档共享的深模块接口。来源文档只写自身事实、证据和差异，不复制这里的通用规则。

## 记录字段

每份来源文档至少包含以下字段和章节。

| 字段 | 必填 | 含义 |
| --- | --- | --- |
| `source_id` | 是 | 全局唯一标识，与 `sources.json` 的 `id` 一致。 |
| `name` | 是 | 来源名称。 |
| `domains` | 是 | 来源负责的域名或子资源域名。 |
| `operator` | 是 | 主管或运营机构。 |
| `content_domains` | 是 | 内容域，与 `sources.json` 一致。 |
| `priority` | 是 | 实施优先级，取 `P0`、`P1` 或 `P2`。 |
| `status` | 是 | 来源当前状态，与审核记录一致。 |
| `access` | 是 | 来源主体的访问等级。 |
| `subresources` | 条件必填 | 访问边界与主体不同的页面、接口或域名。 |
| `license_or_usage` | 是 | 页面声明、授权状态和允许的用途。 |
| `rights_status` | 是 | 来源默认版权标记，与 `sources.json` 和审核记录一致。 |
| `attribution_required` | 是 | 是否要求展示或引用时署名。 |
| `attribution_text` | 是 | 默认署名文本。 |
| `rights_evidence_url` | 是 | 版权声明或授权证据 URL。 |
| `run_modes` | 是 | 统一运行入口允许的模式；不接入自动运行时为空数组。 |
| `confidence` | 是 | 对入口、结构、样本和授权判断的置信度。 |
| `home_url` | 是 | 来源首页或主入口。 |
| `list_url` | 条件必填 | 可复现的列表页或查询入口。 |
| `detail_url` | 条件必填 | 单条记录的长期详情 URL 或详情 URL 模式。 |
| `request` | 是 | 请求方式、参数、分页和请求边界。 |
| `selectors` | 条件必填 | DOM 选择器或 JSON 字段路径。 |
| `samples` | 条件必填 | 至少一条真实样本，受限来源可注明为 0 条及原因。 |
| `field_mapping` | 是 | 来源字段到采集库和业务库的映射。 |
| `downloads` | 是 | 已下载文件、大小、SHA-256 和本地位置，无下载时写原因。 |
| `verified_at` | 是 | 最近一次验证时间，格式为 `YYYY-MM-DD HH:mm Asia/Shanghai`。 |
| `limitations` | 是 | 未验证项、结构风险和访问限制。 |

## 访问等级

| `access` | 含义 | 采集边界 |
| --- | --- | --- |
| `public` | 无需登录即可访问公开内容。 | 可按 robots、频率和版权边界自动采集。 |
| `login-required` | 完整内容、下载或接口需要登录或购买。 | 只登记公开元数据，不保存凭据，不绕过登录或付费边界。 |
| `robots-restricted` | robots 明确限制自动访问。 | 记录 robots 事实，按用户确认的非商业竞赛用途、版权状态和站点压力决定；不绕过访问控制。 |
| `manual-only` | 只能由人工查看或核验。 | 不自动采集正文，样本和证据由人工记录。 |

每个来源只写一个 `access`。同一来源内访问边界不同的页面、接口或域名写入 `subresources`，不得拆出第二个含义重复的 `access`。

## 子资源

`subresources` 用于描述来源内部的访问边界差异，每项至少包含以下信息:

- `name`：子资源名称。
- `domains` 或 `urls`：子资源入口。
- `access`：该子资源的访问等级。
- `in_scope`：是否属于自动采集主体。
- `reason`：范围或访问边界的原因。

不属于自动采集主体的子资源仍要登记，防止后续实现者把站点内所有链接都当成同一来源。

## 状态

| `status` | 含义 |
| --- | --- |
| `draft` | 文档尚未完成，不能作为实现依据。 |
| `approved` | 入口、字段、样本、映射和发布边界均可复现。 |
| `approved-with-gaps` | 主体可用，但存在已记录的缺口。 |
| `blocked` | 访问、结构或合规边界未解决，不能进入实现或业务发布。 |
| `deferred` | 主体保留但当前不接入，必须写明解除条件。 |
| `excluded` | 已决定不采集，必须写明排除原因和证据。 |

来源文档、审核记录和 `sources.json` 的 `status` 必须一致。来源协议状态表示“文档能否指导实现”，不表示“当前是否正在抓取”。

## 证据与样本

- 入口、列表、详情、接口和附件都要记录实际验证时间、HTTP 结果和可复核路径。
- 样本必须来自真实页面、接口或附件，包含详情 URL、关键字段和取得时间。
- 受限来源可以没有正文样本，但要明确写 0 条、原因和不能自动访问的范围。
- 字段定位要同时记录字段名、样本值和所属页面或接口，不能只写选择器。
- 验证时间和证据必须能区分“本轮实测”“历史记录”和“尚未验证”。
- 公开仓库只允许 `crawler/tests/fixtures/evidence/` 下经过脱敏、体积受控的最小测试样本；原始下载仍放在被忽略的 `crawler/download/`。

## URL 与版权标记

每条 raw、stage、std 记录必须保留可复核的详细 URL：

| 字段 | 含义 |
| --- | --- |
| `source_url` | 发现该记录或文件的页面 URL，或本次实际请求 URL。 |
| `long_term_url` | 公告页、数据集页、检索详情页等可长期打开的 URL。 |
| `detail_url` | 单条记录详情 URL，仅在有直接详情页时填写。 |
| `detail_url_status` | `direct` 或 `missing`；missing 时必须保存 locator。 |
| `fetch_url` | 临时签名 URL、短期下载地址或本次抓取地址，不进入长期字段。 |
| `locator` | 附件名、工作表名、页码、行号、表名或查询条件，用于定位无单条详情页的记录。 |

版权状态按来源默认、记录级覆盖：

| 字段 | 取值或含义 |
| --- | --- |
| `rights_status` | `noncommercial-permitted`、`attribution-required`、`assumed-noncommercial-user-risk`、`prohibited`、`unknown`。 |
| `attribution_required` | 是否必须在展示或引用时注明来源。 |
| `attribution_text` | 署名文本。 |
| `rights_evidence_url` | 版权声明或授权证据 URL。 |

`assumed-noncommercial-user-risk` 只用于明确不能公开使用、但用户接受非商业竞赛风险的来源或记录，并在 `extra` 记录风险接受说明。该标记不表示来源授权。
## 详情 URL 与业务发布

业务发布的硬规则：一条来源记录没有可直接打开的长期详情 URL 时，不得进入业务发布。

| 情形 | 处理 |
| --- | --- |
| 有单条长期详情页 | 可以作为业务发布的来源 URL。 |
| 只有列表页或查询结果页 | 不得作为单条记录的详情 URL。 |
| 只有动态查询行，没有行级详情页 | 只留在 raw/stage，不进入 std 或业务发布。 |
| 只有附件行 | 只有在公告详情页可作为长期入口且记录可定位到附件行时，才可发布。 |
| 只有临时签名下载地址 | 不进入长期字段；只保存取得时间、文件哈希和获取方式。 |

动态查询和聚合数据集尤其适用本规则。`aqsc-moa` 的动态查询行没有单条详情页时，只能关联公告详情和附件行；`cnopendata` 没有行级详情 URL 时，只登记公开元数据，不形成业务记录。

## 字段映射

- 每个来源至少给出来源字段、采集库字段和业务库字段三列。
- 采集库字段要落到 `stage_*` 或 `std_*` 实体，业务库字段要写明目标表或“不适用”。
- 自然键、去重键、冲突处理和人工字段保护写在该来源的差异章节，转换器通用规则不在这里重复。
- 无法确认的字段写 `null` 或“未知”，不依据猜测补值。
- 来源字段名和标准字段名都要保留，避免来源改版后失去回溯依据。

## 下载记录

| 字段 | 含义 |
| --- | --- |
| `file_name` | 本地文件名。 |
| `source_url` | 可复核的原始文件 URL。 |
| `detail_url` | 文件所属公告或详情页。 |
| `content_type` | 文件类型。 |
| `size` | 字节数。 |
| `sha256` | 文件内容哈希。 |
| `fetched_at` | 取得时间。 |
| `local_path` | `crawler/download/<域名>/` 下的位置。 |
| `structure` | 工作表、页数、行数或字段结构。 |

无附件或只读不落盘时，写明原因、响应元数据和重跑方式。单文件超过 100MB 时只写 `OVERSIZE.md`，不下载文件本体。

## 语义

### source ID

来源 ID 是稳定、全局唯一的小写 slug，用于任务分发、审核记录、采集日志和自然键。来源 ID 一旦进入样本或映射就不再改名。一个来源可以包含多个域名，但只能有一个来源 ID。

### subresource

子资源是来源内部的采集边界，不是独立来源。子资源的 URL、访问等级和范围必须可被实现者直接识别。

### status

状态表示来源契约的成熟度和发布资格，取值见“状态”一节。实现状态、调度状态和业务审核状态不使用这个字段。

### access

访问等级描述默认采集主体能否匿名访问。登录、购买、robots 和人工限制必须在文档中给出证据，不从“页面公开可见”推断授权。

### license_or_usage

记录页面声明的权利状态、开放许可是否存在、允许的用途和需要授权的行为。公开可访问不等于允许转载、缓存、派生或再分发。

### confidence

置信度只描述证据质量，取 `high`、`medium` 或 `low`，并说明哪些事实已验证、哪些仍是估计。置信度不替代 `status`，也不表示法律授权。

## 来源文档写法

每份来源文档只写以下差异:

- 自身入口、域名、子资源和访问边界。
- 自身请求参数、分页、字段定位和样本。
- 自身自然键、映射例外、下载记录和风险。
- 与共享契约不一致时的证据和原因。

通用字段定义、状态含义、访问等级和详情 URL 规则以本文件为准，来源文档只引用，不复制。
