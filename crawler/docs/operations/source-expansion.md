## 用途边界

- 农业农村部和省级农业农村部门优先作为认证、公告和政策的官方原文来源。
- 全国农技推广服务中心和地方测报来源只保存可复核的测报标题、发布日期、适用区域、病虫害对象、防治建议、详情 URL 和取得时间。
- 招聘来源只收农业、畜牧、水产、种植、乡村基层服务和乡村治理相关岗位，排除个人简历和登录后联系方式。
- 已访问的 `nzrc`、`nongmuhr`、`5ajob` 只作为现有来源索引，不在本文件复制来源契约。
- 待访问条目不得写成已验证，不得从搜索结果摘要推断字段、总页数、详情 URL 或访问等级。

## 验证清单

新增正式来源前至少完成:

1. 实际 HTTP 或 Playwright 打开首页、列表页和至少一条详情页。
2. 核对 robots、登录、版权、访问等级和请求频率。
3. 找到可直接打开单条记录的长期详情 URL，并证明重新访问仍定位同一记录。
4. 记录真实样本、字段定位、分页参数、终止条件和去重键。
5. 写入 `sources/<id>.md`、`reviews/<id>.md`、`sources.json` 和 `operations/evidence-ledger.md`。
6. 运行 `operations/validation.md` 的机械检查。

## Tavily 与 Anysearch 回填

- 搜索发现只产生候选 URL 和待验证说明。
- 核对入口、详情 URL、访问边界和样本后，才能写入 `sources.json`。
- 未回填 `sources.json` 的链接不得进入 raw 调度、std 实体或业务发布。
- 搜索结果中的第三方转载、缓存页和聚合摘要不能替代官方详情页。
