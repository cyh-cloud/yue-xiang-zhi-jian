# 采集规则

状态: active

日期: 2026-10-19

本文是后续爬虫实现的统一运行规则。规则以来源文档中的访问等级、版权状态和项目负责人裁决为准。robots 结果记录为访问事实。`not-found` 不阻断采集，明确禁止仍按真实阻断处理。

## 基本流程

1. 读取 `crawler/docs/sources.json` 和对应来源文档。
2. 记录 robots 事实，检查访问等级、版权、登录要求和站点压力。
3. 用 Playwright 或 HTTP 获取列表和详情。
4. 原始响应进入 raw 层，来源形状进入 stage 层，统一实体进入 std 层。
5. 校验哈希、URL、字段和样本，再由转换器写入建议业务表。

## robots

- 每次运行前按实际 User-Agent 获取并解析 robots。
- robots 明确禁止的路径默认阻断。只有项目负责人书面批准且来源文档记录站点压力评估时，才可按低频率执行。
- robots 返回 404 记录为 `not-found`。`not-found` 允许继续采集和写 raw/stage，候选写 `deferred`，原因 `robots:not-found`，并降低频率、遵守站点版权声明。
- `not-found` 不等于授权，也不自动获得业务发布资格。
- `zhongguoyuyan.cn` 因版权不允许使用数据而标记 `excluded`，不采集正文。
- `5ajob` 的 robots 对普通 UA 和搜索引擎 UA 规则不同，必须按实际 UA 判断。
- robots 返回 403、5xx、连接失败或无法解析时记录 `unknown` 或错误事实并阻断候选，不把失败当允许。

## 登录

- 公开来源优先匿名访问。
- 需要登录的来源登记为 `login-required`；使用用户提供的合法登录态或明确延后。
- 账号密码、Cookie 和会话令牌不进入追踪文件、日志或样本；本地会话只允许放在 ignored 的专用目录。
- 不绕过登录、付费墙、验证码或访问控制。
- `nzrc` 的联系方式需要登录，未登录时写 null，不尝试提取。
- 内置浏览器的已登录状态只用于必要的人工登录态验证，不用于绕过 robots 或批量抓取受限正文。

## 限速

- 同一域名默认 1 至 2 请求/秒。
- 详情页全量回填时保持串行或低并发。
- 夜间和站点响应变慢时自动降速。
- 对 429、403、5xx 和连接重置立即退避，不连续重试。
- 限速配置按来源记录，不写死在单个解析函数。

## 重试

- 只对网络超时、连接错误、429 和 5xx 重试。
- 默认最多 3 次，指数退避加随机抖动。
- 404、410、robots 禁止和登录限制不重试。
- 每次尝试保存 URL、状态码、耗时和错误类型。
- 重试后仍失败写失败记录，不生成伪造样本。

## 超时

- 普通 HTTP 请求默认 30 秒超时。
- Playwright 页面导航默认 45 秒，单页解析总时长设上限。
- 附件下载单独设置超时和最大字节数。
- 大文件下载中断时保留临时文件状态和失败原因，不覆盖已完成文件。
- 来源文档有更严格超时配置时以来源文档为准。

## 单文件 100MB

- 单个下载文件不得超过 100MB。
- 下载前尽量读取 `Content-Length`。
- 超过上限的文件不下载正文，在对应域名目录写 `OVERSIZE.md`，记录 URL、声明大小、原因和人工处理建议。
- 流式下载超过 100MB 时立即中止并删除临时文件。
- Markdown 文档不复制大文件内容或 Base64。

## 下载目录

- 下载根为 `crawler/download/<网站域名>/`。
- 同一域名内按来源和清晰文件名保存，避免路径穿越。
- 文件名保留扩展名，必要时对文件名做安全字符替换。
- 每个目录记录文件 URL、大小、SHA-256、取得时间和 HTTP 状态。
- 不把下载文件放进 `crawler/docs/`。

## SHA-256

- 每个下载文件和 raw 响应都计算 SHA-256。
- 哈希在响应保存完成后计算，不对截断文件计算成功哈希。
- 内容哈希用于变更检测和复现，不用作自然键。
- 同 URL 重新下载得到不同哈希时保留版本记录和取得时间。

## 个人隐私

- 不采集个人简历、求职者信息、身份证、住址、私人电话、私人邮箱和投递记录。
- 公开岗位联系方式只按来源文档允许的字段保存，业务库默认不公开展示。
- 联系人姓名字段只保存来源公开值，不做反查和补全。
- 图片、音频和文件中若含个人信息，按来源授权和最小必要原则处理。
- 日志和错误信息不打印完整 Cookie、手机号、邮箱或身份证号。

## 受限正文

- 登录后可见或付费正文只在用户明确授权范围内采集；个人简历、私人联系方式和投递记录始终排除。
- 受限来源只登记元数据、公开摘要和详情 URL。
- `zhongguoyuyan.cn` 因版权说明排除，只保留排除证据。
- `cass-linguistics` 的登录后语料不进入词条库。
- 第三方文章全文不直接发布到业务库。

## Playwright 优先

- 页面依赖 JavaScript、PostBack、脚本注入字段或前端接口时优先用 Playwright。
- Playwright 适合 `ihchina` 列表页、`nzrc` PostBack 分页、`5ajob` 脚本注入有效期。
- 若存在稳定公开 JSON 或附件，优先直接请求 JSON 或文件，Playwright 作回退。
- 每次 Playwright 解析保存页面 URL、浏览器版本、等待条件和选择器结果。
- 选择器定位为空时记录为样本失败，不用空值生成记录。

## 内置浏览器

- 内置浏览器只用于需要登录态的人工验证或登录操作。
- 不使用内置浏览器绕过 robots、付费墙、验证码或访问控制。
- 登录态只放在 ignored 的本地会话文档，不进入 Git、日志或样本。
- 批量采集优先使用独立 Playwright 会话，内置浏览器不承担后台调度。

## 响应保存策略

- raw 层保存响应正文、URL、取得时间、内容类型、HTTP 状态、大小和 SHA-256。
- HTML、JSON、XLSX、PDF 和音频分别保存原始格式。
- stage 层只保存来源字段的整理结果，不覆盖 raw。
- std 层只保存统一实体和来源引用。
- 响应正文需要压缩时保留解压后的哈希规则和原始编码。
- 失败响应只保存诊断元数据，不伪装成成功快照。

## 运行记录

每次运行至少记录:

- 运行 ID、来源 ID、开始和结束时间。
- 请求数量、成功数、失败数、跳过数和重试数。
- 发现记录数、入库数、冲突数和过期数。
- robots 检查结果、访问等级和限速配置。
- 失败 URL、HTTP 状态、错误类型和下次建议动作。
- 本次运行的代码版本、配置版本和文档版本。

## 待验证

- 各来源的精确限速上限和最佳请求时段。
- Playwright 与 HTTP 回退的自动切换阈值。
- 下载文件保留周期和 raw 层清理策略。
- 登录态验证的人工流程和审计要求。

## 发布门禁

发布使用直接详情 URL 或承载页 URL 加 locator 的机械规则：

- `detail_url_status=direct`：`detail_url` 必须非空。
- `detail_url_status=missing`：长期承载页 URL 必须非空，locator 必须能定位到该条记录。
- 承载页或 locator 缺失时写 `deferred`。
- 承载页 URL 不得伪装成详情 URL。
- 临时签名地址只进入 `fetch_url` 或 raw 证据。

候选状态固定为 `candidate`、`deferred`、`blocked`。数据完整但当前暂不使用时写 `deferred`，不要写 `blocked`。
