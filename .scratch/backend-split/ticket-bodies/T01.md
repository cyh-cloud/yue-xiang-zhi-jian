## What to build

一条可重复执行的检查命令，判定三件事：领域路由模块之间没有 import 边；共享模块不 import 领域模块；
单个领域路由文件不超过 600 行。

此刻仓库里还没有领域模块，检查器必须能空跑通过。此后每批搬迁一落地，违规要立刻可见。
检查器只读代码、不改代码，人工与自动化都能调用。规则通过扫描目录自动发现，不内置文件清单。

## Acceptance criteria

- [ ] 一条命令可运行，合规时退出码为 0，违规时为非 0
- [ ] 当前尚未拆分的代码运行该命令通过
- [ ] 在一个领域路由模块里 import 另一个领域路由模块时报错，并指出这两个模块
- [ ] 共享模块 import 领域模块时报错
- [ ] 单个领域路由文件超过 600 行时报错，并给出文件名与行数
- [ ] 规则随目录自动发现，不含硬编码的文件清单
